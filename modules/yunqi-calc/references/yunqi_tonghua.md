# 运气同化（天符/岁会/太一天符）

## 概念

运气同化是指大运（天干所化之运）与司天之气、岁支（地支五行）之间出现五行属性相同的情况，称为"同化"。同化年气候偏盛，对应脏腑易病。

运气同化分为三种：**天符**、**岁会**、**太一天符**。

## 天符

**天符**：大运五行与司天五行相同。

判断条件：`大运五行 == 司天五行`

### 示例

己丑年：
- 大运 = 土运（甲己化土，己为土运）
- 司天 = 太阴湿土（丑未→太阴湿土，土）
- 土 = 土 → **天符**

### 天符年列表（60甲子中共12年）

| 年干支 | 大运 | 司天 | 同气五行 |
|--------|------|------|----------|
| 己丑 | 土 | 太阴湿土（土） | 土 |
| 己未 | 土 | 太阴湿土（土） | 土 |
| 乙卯 | 金 | 阳明燥金（金） | 金 |
| 乙酉 | 金 | 阳明燥金（金） | 金 |
| 丙辰 | 水 | 太阳寒水（水） | 水 |
| 丙戌 | 水 | 太阳寒水（水） | 水 |
| 丁巳 | 木 | 厥阴风木（木） | 木 |
| 丁亥 | 木 | 厥阴风木（木） | 木 |
| 戊子 | 火 | 少阴君火（火） | 火 |
| 戊午 | 火 | 少阴君火（火） | 火 |
| 戊寅 | 火 | 少阳相火（火） | 火 |
| 戊申 | 火 | 少阳相火（火） | 火 |

## 岁会

**岁会**：大运五行临其本气所主地支之位（运临本辰）。

判断条件：`大运五行 落于 本辰地支`（木运临卯、火运临午、金运临酉、水运临子、土运临辰戌丑未），而非「大运五行 == 地支五行」的朴素判等——后者会把寅/巳/申/亥等非本辰支也收进来（壬寅/癸巳/庚申/辛亥），多算 4 年。

### 地支五行与本辰表

| 地支 | 五行 | 本辰含义 |
|------|------|----------|
| 子 | 水 | 水运本辰 |
| 丑 | 土 | 土运本辰（四季） |
| 寅 | 木 | 非岁会本辰（寅虽属木，但木之本辰为卯） |
| 卯 | 木 | 木运本辰 |
| 辰 | 土 | 土运本辰（四季） |
| 巳 | 火 | 非岁会本辰（巳虽属火，但火之本辰为午） |
| 午 | 火 | 火运本辰 |
| 未 | 土 | 土运本辰（四季） |
| 申 | 金 | 非岁会本辰（申虽属金，但金之本辰为酉） |
| 酉 | 金 | 金运本辰 |
| 戌 | 土 | 土运本辰（四季） |
| 亥 | 水 | 非岁会本辰（亥虽属水，但水之本辰为子） |

### 示例

甲辰年：
- 大运 = 土运（甲己化土）
- 地支 = 辰（土运本辰·四季之一）
- 土运临辰 → **岁会**

### 岁会年列表（60甲子中共8年，运临本辰）

| 年干支 | 大运 | 岁支 | 是否本辰 | 结论 |
|--------|------|------|----------|------|
| 甲辰 | 土 | 辰 | 土运本辰 | 岁会 |
| 甲戌 | 土 | 戌 | 土运本辰 | 岁会 |
| 丙子 | 水 | 子 | 水运本辰 | 岁会 |
| 丁卯 | 木 | 卯 | 木运本辰 | 岁会 |
| 戊午 | 火 | 午 | 火运本辰 | 岁会 |
| 己丑 | 土 | 丑 | 土运本辰 | 岁会 |
| 己未 | 土 | 未 | 土运本辰 | 岁会 |
| 乙酉 | 金 | 酉 | 金运本辰 | 岁会（且为天符，列入太一天符） |

注：寅/巳/申/亥虽地支五行与大运相同，但并非本辰之位，故壬寅、癸巳、庚申、辛亥**不算**岁会。乙酉既为岁会又为天符，列入太一天符，故岁会正位共 8 年（含乙酉），其中 4 年同时是太一天符。

## 太一天符

**太一天符**：既为天符又为岁会，即大运、司天、岁支三者五行同气。

判断条件：`大运五行 == 司天五行 == 岁支五行`（三天符）

又称**三天符**，指大运、司天、岁支三者同气。

### 示例

己丑年：
- 大运 = 土运（甲己化土）
- 司天 = 太阴湿土（丑→太阴湿土，土）
- 地支 = 丑（土）
- 土 = 土 = 土 → **太一天符**

### 太一天符年列表（60甲子中共4年）

| 年干支 | 大运五行 | 司天五行 | 岁支五行 | 是否太一天符 |
|--------|----------|----------|----------|--------------|
| 己丑 | 土 | 太阴湿土（土） | 丑（土） | 是 |
| 己未 | 土 | 太阴湿土（土） | 未（土） | 是 |
| 乙酉 | 金 | 阳明燥金（金） | 酉（金） | 是 |
| 戊午 | 火 | 少阴君火（火） | 午（火） | 是 |

其余天符年（丙辰、丙戌、丁巳、丁亥、戊子、戊寅、戊申）因岁支五行与大运五行不同，故仅为天符而非太一天符。

## 运气同化的意义

| 同化类型 | 同气要素 | 气候特点 | 病理倾向 |
|----------|----------|----------|----------|
| 天符 | 大运+司天 | 该年气候偏盛 | 司天所主脏腑易病 |
| 岁会 | 大运+岁支 | 该年气候偏盛 | 岁支所应脏腑易病 |
| 太一天符 | 大运+司天+岁支 | 气候极偏，该气独盛 | 对应脏腑极易病，病情较重 |

### 各五行同化的病理对应

| 同气五行 | 偏盛之气 | 易病脏腑 |
|----------|----------|----------|
| 木 | 风气 | 肝、脾（木克土） |
| 火 | 热气/火气 | 心、肺（火克金） |
| 土 | 湿气 | 脾、肾（土克水） |
| 金 | 燥气 | 肺、肝（金克木） |
| 水 | 寒气 | 肾、心（水克火） |

## 判断流程

```
1. 计算大运五行（天干化运）
2. 计算司天五行（地支化气→六气→五行）
3. 计算岁支五行（地支本气五行）
4. 判断:
   - 大运 == 司天 → 天符
   - 大运 == 岁支 → 岁会
   - 大运 == 司天 == 岁支 → 太一天符（三天符）
```
