五运六气体现了《黄帝内经》“天人合一”的根本宇宙观——天地阴阳之气按固定节律运行，人体作为小宇宙必须与之相应。

**与现代生活的思想连接**：
运气学提醒我们：时间不是中性的容器，而是充满节律的生命场。尊重节气、顺应气候、调和体质，正是对“天人合一”最朴素的实践。

**核心概念哲学简释**：
- **天人合一**：天地之气与人体之气同源同律，人体健康是天地节律在小宇宙的体现。

## 内经方法论

> 以下为《黄帝内经》方法论框架参考，非医学诊断/治疗建议，具体诊疗须由执业中医师辨证论治。

### 1. yin-yang-balance（素问·阴阳应象大论篇第五、生气通天论篇第三、调经论篇第六十二）

- 来源：`yin-yang-balance`
- 入选理由：阴阳为纲：盛虚方向总判（任一年运皆可参照）；火运/君相火：阴虚则补阳、阳亢则制阳；关联[depends-on]five-elements-network；关联[depends-on]seasonal-regimen

**方法论骨架（I）**
阴阳平衡分析法是一个用于诊断和纠正系统失衡的结构化框架。

其核心操作分为三层:

1. **归阴阳**: 将任何现象归入阴阳两个对立面。阳代表主动、温热、外向、兴奋; 阴代表被动、寒凉、内敛、抑制。这不是贴标签, 而是建立一种"用对立面看问题"的视角。

2. **判盛虚**: 判断哪一方过盛、哪一方不足。"阳胜则热, 阴胜则寒"——失衡必然表现为某一方的症状。关键是区分"某一方过盛"还是"另一方不足", 因为纠正方向完全不同。

3. **用对立面纠正**: 阳盛则补阴抑阳, 阴盛则补阳抑阴。纠正的方向永远是向对立面借力, 而不是直接压制过盛方。

4. **平衡态是目标**: "阴平阳秘, 精神乃治"——系统恢复平衡时, 功能自然正常。平衡不是静态的50/50, 而是动态的相互制约。

这个框架的威力在于: 任何复杂系统, 只要能归阴阳, 就能用同一套逻辑分析。

**可执行步骤（E）**
当 skill 被激活后, agent 应按以下步骤执行:

1. **归阴阳: 将现象归入对立面**
   - 列出当前系统中所有异常表现, 将每一项归入"阳面"(主动/温热/外向/亢奋)或"阴面"(被动/寒凉/内敛/抑制)。
   - 完成标准: 所有异常表现已归入阴阳两列, 且两列的定义一致(不混用不同维度的阴阳)。

2. **判盛虚: 判断失衡方向**
   - 统计阴阳两列的症状数量和严重程度, 判断是"某方过盛"还是"某方不足"。
   - 完成标准: 明确给出判断——"X盛Y虚"或"X虚导致Y相对偏盛", 并说明判断依据。
   - 判停条件: 若症状全部归入一面, 无法形成对立, 则跳到步骤3, 建议用户补充对立面的信息。

3. **用对立面纠正: 制定干预方向**
   - 根据盛虚判断, 确定纠正方向: 盛则抑之/泻之, 虚则补之/助之。纠正的手段来自对立面——阳盛则用阴(清凉/抑制/收敛), 阴盛则用阳(温热/激活/发散)。
   - 完成标准: 给出明确的干预方向(至少1个具体动作), 并指出纠正后的预期平衡态。

**边界（B）**
### 不要在以下情况使用此 skill

- **纯二元对立判断(非此即彼)**: 阴阳是动态平衡关系, 不是"非阴即阳"的分类标签。如果用户的问题是"A好还是B好", 这是选择题, 不是阴阳分析。
- **只有单一变量**: 如果问题只有一个方面, 没有对立面可以参照(如"如何提高效率"), 需要先找到对立面("效率vs质量"), 否则阴阳框架无法展开。

### 作者在书中警告的失败模式

- **阴阳离决**: 当阴阳失衡到极点, 双方彻底脱节, "精气乃绝"——系统崩溃无法挽回。这意味着纠正必须在失衡彻底失控之前进行。
- **重寒则热, 重热则寒**: 极端失衡会出现假象——寒到极点反而表现热象。不能被表面症状迷惑, 要追溯真正的失衡方向。

### 作者的盲点 / 时代局限

- 素问的阴阳框架建立在自然哲学观察之上, 没有现代科学的精确度量手段。在需要精确数据(如血压、血糖数值)的场景下, 阴阳框架应作为辅助视角而非替代诊断。
- 阴阳二分法有时过于简化, 现实中的系统可能存在多维度的矛盾, 此时需要结合五行生克网络来扩展分析维度。

### 容易混淆的邻近方法论

- **辩证法的对立统一**: 形式相似, 但阴阳平衡法更强调整体系统观和可操作的"用对立面纠正"步骤, 不仅仅是哲学分析。
- **平衡计分卡**: 商业管理工具, 关注多维度平衡, 但不提供阴阳框架的"盛虚判断+对立面纠正"操作逻辑。

### 2. five-elements-network（素问·藏气法时论篇第二十二、玉机真藏论篇第十九、阴阳应象大论篇第五）

- 来源：`five-elements-network`
- 入选理由：五行生克：推导五运六气系统连锁；关联[depends-on]emotion-organ-proxy

**方法论骨架（I）**
五行生克网络思维是一套用于分析多要素系统中连锁效应的结构化方法。

其核心逻辑分为四层:

1. **要素归五行**: 将系统中的关键要素归入五类。每一类有其属性和功能。归类的标准不是表面相似, 而是功能角色——谁是生长的力量(木)、谁是驱动的力量(火)、谁是承载转化的力量(土)、谁是收敛规范的力量(金)、谁是蕴藏滋养的力量(水)。

2. **画生克关系图**: 五行之间存在两种基本关系——"生"(滋养、促进)和"克"(制约、抑制)。相生链条: 木生火、火生土、土生金、金生水、水生木, 构成正向循环。相克链条: 木克土、土克水、水克火、火克金、金克木, 构成制衡循环。

3. **沿链条推导**: 某一行的变化会沿相生链向下传导(母病及子), 也会沿相克链产生压力(乘——过度克制, 或侮——反克)。因此, 局部的变化可以推导出全局的连锁效应。

4. **找到关键干预点**: 连锁效应意味着"治一处牵全局"。干预的关键不是直接作用于症状所在的行, 而是找到链条上的关键节点——生链条上游(补母)或克链条的对立面。

这个框架的独特价值在于: 它把"事物相互影响"的模糊认知变成了一套可操作的关系图+推导规则。

**可执行步骤（E）**
当 skill 被激活后, agent 应按以下步骤执行:

1. **要素归五行: 将关键要素分类**
   - 列出系统中所有相关要素(目标5个左右), 根据其功能角色归入五行分类: 生长/启动(木)、驱动/活跃(火)、承载/转化(土)、收敛/规范(金)、蕴藏/滋养(水)。
   - 完成标准: 每个要素都已归入一个类别, 且归类理由清晰(不是随意贴标签)。

2. **画生克关系图: 建立要素间的互动关系**
   - 标出所有要素之间的"生"(促进/滋养)关系和"克"(制约/抑制)关系。画出完整的生克网络图。
   - 完成标准: 图中包含所有相生关系和相克关系, 且链条形成闭合循环(没有孤立的节点)。
   - 判停条件: 若要素少于3个, 无法形成有意义的网络, 建议改用 yin-yang-balance。

3. **沿链条推导: 预测连锁效应并找到干预点**
   - 从当前出问题的要素出发, 沿相生链和相克链分别推导: 会"生"出什么新问题? 会"克"到哪个要素? 反馈是否会回到起点形成循环? 然后确定干预点——在链条的哪个环节介入能阻断恶性传导。
   - 完成标准: 给出至少一条传导路径的推导, 以及一个具体的干预建议(作用于链条的哪个节点、预期效果)。

**边界（B）**
### 不要在以下情况使用此 skill

- **简单线性因果**: 如果问题是"A导致B", 一因一果, 没有连锁和反馈, 用五行生克是杀鸡用牛刀。
- **只有两个要素**: 五行网络至少需要三个要素才能形成链条。只有两个对立要素时, 应使用 yin-yang-balance。

### 作者在书中警告的失败模式

- **相乘与相侮的区分**: 克制过度叫"乘"(欺负), 是病理性的; 被克方反扑叫"侮"(反克), 也是病理性的。正常的克是制衡, 异常的乘和侮都会导致系统紊乱。不能把所有"克"关系都视为负面。
- **五脏有病则各传其所胜**: 疾病传变有确定方向, 不是随机扩散。忽略传变方向会导致"头痛医头脚痛医脚"——治了标处, 病已传到下一个脏腑。

### 作者的盲点 / 时代局限

- 素问的五行归类(五脏、五色、五味、五志等)是基于古代哲学和临床观察的归纳, 在现代应用中需要灵活转化。不是所有系统都能完美归入五行——如果要素恰好是4个或6个, 可以选取最关键的5个来分析。
- 五行框架侧重"均衡"和"循环", 对单方向的突变(如外力冲击导致系统瞬间崩溃)解释力有限。

### 容易混淆的邻近方法论

- **系统思考中的因果回路图**: 形式类似, 但五行生克提供了一套预设的关系类型(生/克)和推导规则(乘/侮/母病及子), 比自由绘制因果图更有结构。
- **SWOT分析**: 也是分类框架, 但SWOT只有4个静态类别, 没有五行生克之间的动态关系链条。

> 出处：《《黄帝内经·素问》 黄帝与岐伯等》藏气法时论篇第二十二、玉机真藏论篇第十九、阴阳应象大论篇第五

### 3. emotion-organ-proxy（素问·阴阳应象大论篇第五; 举痛论篇第三十九）

- 来源：`emotion-organ-proxy`
- 入选理由：金/阳明燥金在泉：悲忧属肺；关联[composes-with]five-elements-network

**方法论骨架（I）**
情绪不是单纯的心理现象,而是有明确生理方向的气机运动。每种核心情绪对应一个脏腑,
且有特定的气机方向:怒→气上(肝)、恐→气下(肾)、喜→气缓(心)、悲→气消(肺)、
思→气结(脾)、惊→气乱。长期处于某种情绪,对应的脏腑就会因气机偏颇而受损。
反过来,利用五行相克的原理,可以用一种情绪来制约另一种情绪——悲胜怒(金克木)、
恐胜喜(水克火)、怒胜思(木克土)、喜胜忧(火克金)、思胜恐(土克水),
这就是"以情胜情"的调节术。但这不是简单的"用开心对抗悲伤",
而是有一套严格的情绪→脏腑→气机→调节策略的分析链。

**可执行步骤（E）**
当 skill 被激活后, agent 应按以下步骤执行:

1. **识别用户当前的主导情绪**
   - 完成标准: 已从用户描述中识别出当前最强烈、最持续的情绪类型(怒/喜/悲/恐/思/惊中的一种或几种)

2. **映射到对应脏腑和气机方向**
   - 完成标准: 已将主导情绪映射到对应脏腑(怒→肝、喜→心、悲→肺、恐→肾、思→脾)和气机方向(上/下/缓/消/结/乱),并指出可能的身体症状

3. **选择调节策略(疏导或以情胜情)**
   - 完成标准: 已根据情绪类型给出两种调节路径:
     - 疏导:让该情绪自然流动而非压抑(如允许悲伤哭泣而非强行振作)
     - 以情胜情:利用五行相克关系选择制约情绪(如悲胜怒、恐胜喜),并说明如何安全地引入制约情绪
   - 判停条件:若用户情绪状态极度不稳定,建议优先寻求专业心理帮助,不建议自行使用以情胜情

**边界（B）**
### 不要在以下情况使用此 skill

- 严重的心理疾病(抑郁症、焦虑症、创伤后应激障碍等)需要专业心理/精神科干预,以情胜情不能替代治疗
- 急性身体症状(突然剧烈头痛、胸痛等),即使与情绪相关也应先排除器质性病变
- 用户没有明确的情绪背景,只是单纯的身体症状——不要强行用情绪解释所有身体问题

### 作者在书中警告的失败模式

- 以情胜情操作不当可能加重病情:用喜悦压制悲伤,看似有效实则可能导致"火克金"过度,肺气郁结更深
- 情绪调节不是压抑:素问讲的是"胜"而非"灭",是用制约情绪来平衡过激情绪,而不是消灭某种情绪
- 九气(怒喜悲恐寒炅惊劳思)中寒、炅、劳不是情绪而是物理/行为因素,不要把所有气机变化都归结为情绪

### 作者的盲点 / 时代局限

- 情志脏腑的对应关系基于五行推演和临床观察,现代身心医学有更精确的神经-内分泌机制解释
- 以情胜情缺乏系统化的操作规范和适应症界定,实际应用中风险较高
- 素问没有区分正常情绪反应和病理性情绪障碍,现代人面临的心理问题复杂度远超古代

### 容易混淆的邻近方法论

- "情绪管理"是现代心理学的概念,关注的是**调节情绪本身**,情志脏腑模型关注的是**情绪对身体脏腑的影响以及反向利用情绪来调节身体**
- "身心一体"是一种哲学立场,情志脏腑模型是一套**可操作的分析-调节框架**:情绪→脏腑→气机→调节策略,每一步都有具体的对应关系
