## 静顺汤（辰戌年 · 太阳寒水司天 · 太阴湿土在泉）

**rag_key**: `taiyang_hanshui_sitian` ｜ **源行号**: 三因极一病证方论.txt L2001-2009

### 组成
白茯苓、木瓜干（各一两）、附子（炮去皮脐）、牛膝（酒浸，各三分）、防风（去叉）、诃子（炮去核）、甘草（炙）、干姜（炮，各半两）。

### 主治
治辰戌岁，太阳司天，太阴在泉，病身热头痛，呕吐气郁，中满瞀闷，少气足痿，注下赤白，肌腠疮疡，发为痈疽。

### 六气病机推演
辰戌之岁，太阳司天，太阴在泉，气化营运先天。
- **初之气**，乃少阳相火加临厥阴风木，民病瘟，身热头疼，呕吐，肌腠疮疡。
- **二之气**，阳明燥金加临少阴君火，民病气郁中满。
- **三之气**，太阳寒水加临少阳相火，民病寒，反热中，痈疽注下，心热瞀闷。
- **四之气**，厥阴风木加临太阴湿土，风湿交争，民病大热少气，肌肉痿，足痿，注下赤白。
- **五之气**，少阴君火加临阳明燥金，民气乃舒。
- **终之气**，太阴湿土加临太阳寒水，民乃惨凄孕死。

### 治法
用甘温以平水，酸苦以补火，抑其运气，扶其不胜。

### 六步时令加减
| 时段 | 加减 |
|------|------|
| 大寒—春分 | 去附子，加枸杞半两 |
| 春分—小满 | 依前入附子、枸杞 |
| 小满—大暑 | 去附子、木瓜、干姜，加人参、枸杞、地榆、香白芷、生姜各三分 |
| 大暑—秋分 | 依正方，加石榴皮半两 |
| 秋分—小雪 | 依正方 |
| 小雪—大寒 | 去牛膝，加当归、芍药、阿胶炒各三分 |

## 审平汤（卯酉年 · 阳明燥金司天 · 少阴君火在泉）

**rag_key**: `yangming_zaojin_sitian` ｜ **源行号**: L2011-2022

### 组成
远志（去心，姜制炒）、紫檀香（各一两）、天门冬（去心）、山茱萸（各三分）、白术、白芍药、甘草（炙）、生姜（各半两）。

> **订正**：旧传组成有"紫菀、桂枝、人参"，系后世转引之误，公版原方无此三味，有远志、紫檀香、白术。今据原书订正。

### 主治
治卯酉之岁，阳明司天，少阴在泉，病者中热，面浮鼻鼽，小便赤黄，甚则淋，或疠气行，善暴仆，振栗谵妄，寒疟痈肿，便血。

### 六气病机推演
卯酉之岁，阳明司天，少阴在泉，气化营运后天。
- **初之气**，太阴湿土加厥阴木，此下克上，民病中热胀，面目浮肿，善眠，鼽衄嚏欠，呕吐，小便黄赤，甚则淋。
- **二之气**，少阳相火加少阴君火，此臣居君位，民病疠大至，善暴死。
- **三之气**，阳明燥金加少阳相火，燥热交合，民病寒热。
- **四之气**，太阳寒水加太阴湿土，此下土克上水，民病暴仆，振栗谵妄，少气，咽干引饮，心痛，痈肿疮疡，寒疟骨痿，便血。
- **五之气**，厥阴风木加阳明燥金，民气和。
- **终之气**，少阴君火加太阳寒水，此下克上，民病温。

### 治法
宜咸寒以抑火，辛甘以助金，汗之，清之，散之，安其运气。

### 六步时令加减
| 时段 | 加减 |
|------|------|
| 大寒—春分 | 加白茯苓、半夏（汤洗去滑）、紫苏、生姜各半两 |
| 春分—小满 | 加玄参、白薇各半两 |
| 小满—大暑 | 去远志、山茱萸、白术，加丹参、泽泻各半两 |
| 大暑—秋分 | 去远志、白术，加酸枣仁、车前子各半两 |
| 秋分—大寒 | 依正方 |

## 升明汤（寅申年 · 少阳相火司天 · 厥阴风木在泉）

**rag_key**: `shaoyang_xianghuo_sitian` ｜ **源行号**: L2025-2033

### 组成
紫檀香、车前子（炒）、青皮、半夏（汤洗）、酸枣仁、蔷蘼、生姜、甘草（炙，各半两）。

> **订正**：旧传组成有"木瓜、茯苓"，系后世转引之误，公版原方无此二味，有紫檀香、车前子、青皮、蔷蘼。今据原书订正。

### 主治
治寅申之岁，少阳相火司天，厥阴风木在泉，病者气郁热，血溢目赤，咳逆头痛，胁满呕吐，胸臆不利，聋瞑渴，身重心痛，阳气不藏，疮疡烦躁。

### 六气病机推演
寅申之岁，少阳相火司天，厥阴风木在泉，气化营运先天。
- **初之气**，少阴君火加厥阴木，民病温，气拂于上，血溢目赤，咳逆头痛，血崩胁满，肤腠中疮。
- **二之气**，太阴土加少阴火，民病热郁，咳逆呕吐，胸臆不利，头痛身热，昏愦脓疮。
- **三之气**，少阳相火加相火，民病热中，聋瞑，血溢脓疮，咳呕鼽衄，渴嚏欠，喉痹目赤，善暴死。
- **四之气**，阳明金加太阴土，民病满，身重。
- **五之气**，太阳水加阳明金，民避寒邪，君子周密。
- **终之气**，厥阴木加太阳水，民病开闭不禁，心痛，阳气不藏而咳。

### 治法
宜咸寒平其上，辛温治其内，宜酸渗之，泄之，渍之，发之。

| 春分—小满 | 加丁香一钱 |
| 小满—大暑 | 加漏芦、升麻、赤芍药各半两 |

## 备化汤（丑未年 · 太阴湿土司天 · 太阳寒水在泉）

**rag_key**: `taiyin_shitu_sitian` ｜ **源行号**: L2035-2045

### 组成
木瓜干、茯神（去木，各一两）、牛膝（酒浸）、附子（炮，去皮脐，各三分）、熟地黄、覆盆子（各半两）、甘草（一分）、生姜（三分）。

### 主治
治丑未之岁，太阴湿土司天，太阳寒水在泉，病者关节不利，筋脉拘急，身重萎弱，或温疠盛行，远近咸若，或胸腹满闷，甚则浮肿，寒疟血溢，腰痛。

### 六气病机推演
丑未之岁，太阴湿土司天，太阳寒水在泉，气化营运后天。
- **初之气**，厥阴风木加风木，民病血溢，筋络拘强，关节不利，身重筋痿。
- **二之气**，大火正，乃少阴君火加君火，民病温疠盛行，远近咸若。
- **三之气**，太阴土加少阳火，民病身重肿，胸腹满。
- **四之气**，少阳相火加太阴土，民病腠理热，血暴溢，疟，心腹胀，甚则浮肿。
- **五之气**，阳明燥金加阳明燥金，民病皮肤寒气及体。
- **终之气**，太阳寒水加寒水，民病关节禁固，腰痛。

### 治法
用酸以平其上，甘温治其下，以苦燥之，温之，甚则发之，泄之，赞其阳火，令御其寒。

| 春分—小满 | 去附子，加天麻、防风各半两 |
| 小满—大暑 | 加泽泻三分 |
| 大暑—大寒 | 依正方 |

## 正阳汤（子午年 · 少阴君火司天 · 阳明燥金在泉）

**rag_key**: `shaoyin_junhuo_sitian` ｜ **源行号**: L2047-2057

### 组成
白薇、玄参、川芎、桑白皮（炙）、当归、芍药、旋复花、甘草（炙）、生姜（各半两）。

### 主治
治子午之岁，少阴君火司天，阳明燥金在泉，病者关节禁固，腰痛，气郁热，小便淋，目赤心痛，寒热更作，咳喘；或鼻鼽，嗌咽吐饮，发黄瘅，喘，甚则连小腹而作寒中，悉主之。

### 六气病机推演
子午之岁，少阴君火司天，阳明燥金在泉，气化营运先天。
- **初之气**，太阳水加厥阴木，民病关节禁固，腰痛，中外疮疡。
- **二之气**，厥阴风木加少阴君火，民病淋，目赤，气郁而热。
- **三之气**，少阴君火加少阳火，民病热厥心痛，寒热更作，咳喘目赤。
- **四之气**，太阴土加湿土，民病黄瘅鼽衄，嗌干吐饮。
- **五之气**，少阳火加阳明金，民乃康。
- **终之气**，阳明金加太阳水，民病上肿咳喘，甚则血溢，下连少腹，而作寒中。

### 治法
宜咸以平其上，苦热以治其内，咸以软之，苦以发之，酸以收之。

## 敷和汤（巳亥年 · 厥阴风木司天 · 少阳相火在泉）

**rag_key**: `jueyin_fengmu_sitian` ｜ **源行号**: L2059-2068

## 用药禁忌（六气通则）

> 凡六气，数起于上而终于下。岁半之前，自大寒后，天气主之；岁半之后，自大暑之后，地气主之；上下交互，气交主之。
>
> 司气以热，用热无犯；司气以寒，用寒无犯；司气以凉，用凉无犯；司气以温，用温无犯。司气同其主，亦无犯；异主，则少犯之，是谓四畏。
>
> ——《三因极一病证方论》卷之五（源行号 L2069-2070）
