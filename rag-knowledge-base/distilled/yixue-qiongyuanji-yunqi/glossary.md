# 《医学穷源集·卷二》运气专论 术语校对（歧义澄清）

> 本章对本书关键术语做歧义校对，避免研读时误读。所有释义均据本书逐字转录与上下文。

## 一、太乙移宫 / 九宫 / 八风

- **太乙（太一）**：天神之最贵者，即北极；北极不动而运周天，太一游宫终而复始。
- **九宫**：太一游宫的九个方位宫（叶蛰/天留/仓门/阴洛/天宫/玄委/仓果/新洛/中宫）。**干（西北）巽（东南）二宫各少一日**（天地门户、不足之方）；"其曰九宫者，土旺四维，每季末十八日，太一居于中宫也"——中宫按季末十八日计。
- **八风**：实风（从所居宫来，主生长万物）vs 虚风（从冲后来，伤人应藏）。八虚风各有舍藏：大弱风舍心、谋风舍脾、刚风舍肺、折风舍小肠、大刚风舍肾、凶风舍大肠、婴儿风舍肝、弱风舍胃。
- **三虚**：乘年之衰（五少岁运不及＋司天失守）＋逢月之空（望后血虚气去）＋失时之和（主客相犯、时令失正）。三虚相合乃平居亦病。

## 二、升降 / 迁正 / 退位

- **升之不前**：旧岁在泉之右间 → 新岁司天之左间，因天星/中运/阴年气衰窒抑而不前（木欲升金窒等，病在相应脏）。
- **降之不下**：旧岁司天之右间 → 新岁在泉之左间，因地星/中运/旧司天有余不退而不得降地。治法：**折其所胜以舒本经之郁**。
- **不迁正**：新司天之气有郁（本年司天未得位），当**泻新司天之郁以通之**。
- **不退位**：旧司天之气有余（上年司天未退），当**折旧司天之气有余以退之**。
- ⚠️ 易混：不迁正（责新司天）与不退位（责旧司天）治法相反，不可颠倒。

## 三、刚柔失守 / 三年化疫 / 疫由人事

- **刚柔**：上干为刚，下干为柔。**刚柔失守**＝上下（干支/司天在泉）孤立失位，岁运气衰。
- **三年化疫**：刚柔孤立、郁极而发，三年化为疫疠（非本年即发）。五年详例见 ch03。
- **疫由人事**：天运戾气（刚柔失守三年来复）与人事失调（血气耗越、召殃招尤）双因；主张"人定胜天"。
- ⚠️ 易混："化疫"（三年深患）与"不退位不迁正之浅患"（本年即见、调之即已，五运不为失守）须区分。

## 四、化数生成 / 灾宫

- **生成数**：太过成数、不及生数（河图五行生成数）；例外戊寅/戊申二太征用生数。
- **灾宫**：五少各灾一正宫（己五/乙七/丁三/辛一/癸九）；五太灾所胜之宫；制则灾本宫。⚠️ 本书明言"往往不验"，不可机械套用。

## 五、方月图说 / 山川方隅

- **方月**：六气各归不胜而为化，各命所在方月征之；客气之化随方位/月份推移。
- **方隅偏胜**：西北多燥多寒、东南多湿多热，崇卑高下地里偏胜，天气因而异其化。
- ⚠️ 易混："言理而不言数"——运气是气化之理非可机械套算之数；"即理以征数"方为正解。

## 六、本标中从化 / 治病标本

- **本/标/中气**：风赛热湿火燥为本，三阴三阳为标，表里相络为中气（义出六微旨）。
- **从化三型**：从本（少阳/太阴）、从本从标（少阴/太阳）、从中（阳明/厥阴）。
- **治病标本**：总以治本为急务；惟中满及二便不利不论标本先治；有余先治本、不足先治标；间者并行、甚者独行。⚠️ 本书明斥俗谚"急则治其标"之滥用。

## 七、脏腑苦欲 / 五禁 / 五味过伤

- **脏腑苦欲**：就脏气之"苦/欲"定补泻（如肝苦急甘缓、肝欲散辛补酸泻）。
- **六气客主补泻正味**：就主客气本位定补泻（如木位之主泻酸补辛、厥阴之客辛补酸泻甘缓）。⚠️ 两套体系，不可混同（见 patterns A3）。
- **五禁**：辛走气、咸走血、苦走骨、甘走肉、酸走筋（病所走者无多食）。
- **五味过伤**：酸伤筋(辛胜酸)、苦伤气(咸胜苦)、甘伤脾(酸胜甘)、辛伤皮毛(苦胜辛)、咸伤血(甘胜咸)；肥令人内热、甘令人中满。

## 八、十二经配天干

- 歌：甲胆乙肝丙小肠，丁心戊胃己脾乡，庚大肠辛肺，壬膀胱癸肾，三焦归丙，包络从丁。
- 五脏（阴）：肾癸水、心丁火、肝乙木、肺辛金、脾己土、心包亦丁。六腑（阳）：胃戊、胆甲、大肠庚、小肠丙、膀胱壬、三焦亦丙。
