# 核心框架与心智模型

本书是《医学穷源集·卷二》运气专论的整理。王肯堂（明）原著、殷宅心辑释，汇辑《内经》运气之说的若干**纵深专论**，与本项目既有五书**互补而非替代**：

本书在「六书链」中的独特定位——**灾变纵深**：

1. **唯一系统讲「刚柔失守三年化疫」**：把《内经》「不迁正/不退位」推到「五年化疫」的详例（甲子土疫、丙寅水疫、庚辰金疫、壬午木疫、戊申火疫），并给出「当先补某脏、次泄某气」的防疫次第——这是运气学与温疫学衔接的关键文献。
2. **唯一明言「疫由人事」「人定胜天」**：反对把疫疠单纯归为天运戾气，强调「血气耗越、召殃招尤」的人事失调一面，并以李东垣普济消毒饮汴京大疫为证——把运气学说从「天命灾异」拉回「天人相参、人可胜天」。
3. **唯一系统回答「运气为什么不验」**：方月图说（天下万余里，南旱北水、西热东寒，气候不齐）＋山川方隅气候不同论（西北多燥多寒、东南多湿多热，崇卑高下地里偏胜），直指机械套用经文「按年豫决」如刻舟求剑。
4. **太乙移宫九宫八风**：与 asset37 象数基础互补，独有「风从所居宫来为实风、从冲后来为虚风、虚风舍藏」与「三虚致疫」之说。
5. **六气本标中从化解＋药法摘录**：与 asset38 标本中见互证；药法摘录（五味补泻/脏腑苦欲/六气客主补泻正味）为全书最贴近「用方」的一章，**已置最强警告**。

## 本书灵魂（务必先读，逐字）

- 疫由人事论（逐字，人定胜天锚点）：**「盖人定胜天，而五行之戾气，罔敢干焉。」**
- 疫由人事论（逐字，防疫次第）：**「若疫将发而思豫却之方，当求诸运气及人事所以化疫之由，而折其胜气，资其化气，乃克有济。」**
- 方月图说（逐字，运气不验之由）：**「如拘执经文，按年豫决，是犹刻舟求剑，守株待兔之智也。」**
- 运气总论（逐字，活法红线）：**「得其要者，一言而终；不知其要，流散无穷。」** 兼引「未至而至，此谓太过……至而不至，此谓不及」。
- 五运失守（逐字，郁极化疫）：**「一经上下失守，反为大虚，敌得乘之，郁为疫疠。」**
