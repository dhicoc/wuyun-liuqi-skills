# 核心框架与心智模型

本书是陈无择《三因方》"司天运气方"的歌诀化整理 + 王旭高按语，专论"因岁运太过不及、司天在泉客气"而设的十六方及运气推算工具。三层结构：

1. **五运大运方（十干年）**：甲~癸十年，各主一方（木火土金水太过/不及 → 相应脏受邪 → 对应方）。
2. **六气客气方（十二支年）**：子午~巳亥六年支，各对应一经司天、一经在泉，各主一方，且方随六气（初之气至终之气）加减。
3. **工具层**：运气推算歌诀（司天/主客运气/天符岁会）+ 六淫治例（风、热、湿、火、燥、寒的通用治法）。

## 王旭高核心按语（本书灵魂，务必先读）
- 运气方"不出《内经》六淫治例，与夫五脏苦欲补泻之义"。
- **反机械对应（关键）**："假令风木之年，而得燥金之年之病，即从燥金之年方法求治"——以"当年所感之病"定方，而非以"年干支"定病。"若谓其年必生某病，必主某方，真是痴人说梦矣。"
- 十六方"不过示人以规矩耳。病有万变，药亦万变，圆机之士，不须余赘矣"——强调活法，反对套方。
