# 核心框架与心智模型

本书是宋·刘温舒（朝散郎、太医学司业）《素问入式运气论奥》的机制纵深整理。它是运气学史上**第一本独立的运气专著**（承《素问》运气七篇、王冰次注及《玄珠密语》而专论之），使原本散见、难施的运气之学成为可操作的知识模型。全书**三卷、三十论，另附《五行胜复论》**——与本项目既有四书**互补而非替代**：

| 层级 | 书名 | 资产 | 侧重 |
|------|------|------|------|
| **专论·机制纵深层（本书）** | 素问入式运气论奥（刘温舒） | asset38 | 卷上象数纵深（纳音／六化／五行本义／日刻／标本）+ 卷下机制纵深（胜复·五郁·六病·六脉·治法·五行胜复论＝亢害承制机制化）；第一本独立运气专著，承前启后 |
| 方源层 | 三因极一病证方论·卷五运气诸方（陈无择） | asset36 | 十六方药物组成、炮制分量、主治、煎服与随气加减（运气用方原方层） |
| 歌诀层 | 运气证治歌诀（王旭高） | asset34 | 以歌诀体重述十干运方与六支气方、六淫治例（运气证治方歌层） |
| 推算框架广度层 | 医宗金鉴·运气要诀（吴谦） | asset35 | 太极阴阳、五运六气推算、天符岁会、南北政体例广度 |
| 图翼·象数基础层 | 类经图翼·卷一·卷二「运气」（张介宾） | asset37 | 太极—阴阳—五行生成数—气数哲学地基 + 图翼推算细节（五音建运、南北政脉不应等深度） |

五书互补（专论机制 → 图翼象数 → 推算框架 → 歌诀 → 方源），**任何一书的研读都不可取代另外四书，更不可取代执业中医师面诊**：

1. **专论·机制纵深层（本书）**：填补四书在「气化失衡—自稳—病机」机制上的空白（纳音/六化/胜复/五郁/六病/六脉/五行胜复论）。
2. **图翼·象数基础层（类经图翼）**：补全太极—阴阳—五行生成数—气数根基与图翼推算细节。
3. **推算框架广度层（医宗金鉴）**：提供「按年干支推算运气格局」的全框架广度。
4. **歌诀层（王旭高）**：把同一套运气治法编成方歌，便于记诵与证治对照。
5. **方源层（三因）**：把运气格局落到十六个原方，提供「用方」的文献源流。

## 本书灵魂（务必先读，逐字）
- 序（逐字）：**「括上古运气之秘文，撮斯书阴阳之精论」**；**「畏医药之差误遗人，夭殃绝人长命尔」**。
- 卷下·五行胜复论结语（逐字，活法锚点）：**「安得圆机之士，而与之共论五行哉！」**
- 论六病（逐字，不可拘于气运之警）：**「免拘于气运，粗见补写之误与不误也」**。
- 五行胜复论（逐字，亢害承制机制化）：**「高者抑之，下者举之，化者应之，胜者复之」**。
