# 第七章 🛑 最强警告章（禁止自行开方 / 剂量推算 / 体质诊断 / 替代就医）

> 🛑🛑🛑 **最强安全警告——本 skill 最易被误用之处，务必逐字读完**
> 本章是本蒸馏安全纪律的**最高红线**，用语最严厉。它对应项目整体红线：**凡「求开方、算命化、临床」类请求，一律拒止**。本章与 `SKILL.md` 头警告、`cheatsheet.md` 最高级警告共同构成**三重安全包裹**，三处都必须存在、都不得删改。

## 一、绝对禁止（逐条，无例外）
1. **禁止自行开方**：不得依据本 skill 任何内容（纳音、六化、五行本义、标本中见、胜复、五郁、六病、六脉、治法、亢害承制等）为自己或他人开方、荐方、配药。取方、用量、加减、合用**只能**由持证中医师面诊后决定。
2. **禁止剂量推算**：底本所及的分量、炮制、主治均属历史文献原貌，**不得**自行换算为现代克数、不得自行补全、不得自行增减。任何现代用量须由执业中医师确定。
3. **禁止体质诊断 / 自诊自疗**：不得把「岁运太过不及」「司天在泉」「天符岁会」「南北政脉不应」「胜复／五郁／六病／六脉」当作「我今年什么运、我会得什么病、我是什么体质」的自诊依据；运气格局≠健康宿命，更不得据此自行服药预防或治疗。
4. **禁止替代就医**：本 skill **不是**医疗建议、**不是**诊疗工具。任何健康问题、任何急症（含疑似心脑血管、呼吸、消化急症），**立即就医**，由正规医疗机构与持证中医师处置。
5. **禁止算命化 / 宿命化**：运气学是古代探讨「气化—人体」关系的学术框架，**不是**算命、不是预测个人命运或健康的工具。任何将运气学用于「算命」「改运」「趋吉避凶」「按出生年断体质断吉凶」的取向，一律拒止。

## 二、项目红线（重申）
- 红线一：**求开方** —— 凡请求「给我开个运气方／按我出生年开方／我该吃哪方」，**拒止**，引导至执业中医师。
- 红线二：**算命化** —— 凡请求「算我今年运势／健康命数／趋避／断体质」，**拒止**，说明运气学为文献学术框架、非算命。
- 红线三：**临床** —— 凡涉及具体诊断、辨证、用药、剂量、疗效判断，**拒止**，说明须面诊持证中医师。

## 三、为什么必须如此严格（特别警示本书机制文字）
本书出自宋本《素问入式运气论奥》，所论的纳音、六化、五行本义、标本中见、胜复、五郁、六病、六脉、治法、五行胜复论（亢害承制机制化），均属古代机制学术框架原貌，未经现代临床重订与个体辨证即套用，风险极高。尤其须特别强调：
- **「亢害承制／胜复／五郁／六病」等机制文字，绝不可直接当作自疗指南。** 它们是气化失衡—自稳—病机的古代学理描述，真实发病必因「其人脏腑不和」、四诊合参而后定，绝不可机械套用。
- 本书明言「免拘于气运，粗见补写之误与不误也」「必先岁气，无伐天和」，正是对机械套用、粗工误治的告诫，反证此类文字不可自疗照搬。
- 本 skill 的全部价值仅在**帮助你读懂这部运气学古籍的专论机制与亢害承制框架**，而非提供任何可用于实际的医疗判断。

- 与三因《运气诸方》（方源层，asset36）、王旭高《运气证治歌诀》（歌诀层，asset34）、医宗金鉴《运气要诀》（推算框架广度层，asset35）、类经图翼·运气（图翼·象数基础层，asset37）对照，理解五书互补。
