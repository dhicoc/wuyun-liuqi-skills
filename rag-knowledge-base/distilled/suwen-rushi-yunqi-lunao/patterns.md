# 研读 / 推算模式（可复用）

> 本节归纳本蒸馏可复用的「研读式」模式。模式仅用于**文献框架对照与专论机制溯源**，所有取方、用量、加减、合用、体质判断均须由执业中医师面诊后决定，本 skill 不输出任何实际处方或个性化建议。

## 模式 1：专论机制纵深补足通用推算
- **输入**：某年干支（如「甲己」）。
- **步骤**：
  1. 通用推算（`modules/yunqi-calc/` 或 `scripts/calculate_yunqi_api.py`）给格局：甲己 → 土运、少阴君火司天。
  2. 查 `cheatsheet.md` 表 9 / `chapters/ch03-wuyun.md`：甲己 → 黅天下临 → 土运；五音建运「宫，中也」。
  3. 回本书补「专论机制」：纳音为何金先（ch02）、六化如何分君火相火（ch02）、亢害承制如何解释气化失衡（ch05）。
- **用途**：从通用格局落到专论机制细节，补足医宗金鉴（asset35）推算框架所缺的机制纵深。

## 模式 2：图翼细节／纳音／六化补足象数
- **图翼·象数基础层（asset37）**：补太极—阴阳—五行生成数—气数根基。
- **本书象数纵深（asset38）**：以纳音（同类娶妻、隔八生子、金先、阳生於子下生阴生於午上生）、六化（君火相火分论）、五行本义（木触火化金禁水润土吐）、标本中见，补图翼未专论的象数纵深。
- **用途**：「图翼补根基 → 本书补纳音／六化纵深」双轨象数研读。

## 模式 3：五书多轨对照
- **专论·机制纵深层（本书，asset38）**：纳音／六化／胜复／五郁／六病／六脉／五行胜复论。
- **图翼·象数基础层（asset37）**：太极—阴阳—五行生成数—气数＋图翼推算细节。
- **推算框架广度层（医宗金鉴，asset35）**：按年干支推算全框架。
- **歌诀层（王旭高，asset34）**：十干运方／六支气方／六淫治例方歌。
- **方源层（三因，asset36）**：十六方组成、炮制、主治、煎服、随气加减。
- **用途**：「框架推格局 → 图翼补象数 → 本书补机制 → 歌诀助记诵 → 方源取原方」五书互补闭环；再走 RAG（asset1/2/4/5/10/14）补跨书病机与医案。

## 模式 4：亢害承制 → 胜复闭环（理解气化失衡）
- **输入**：某不及岁运（如「木运少角」）。
- **步骤**：
  1. 查 `cheatsheet.md` 表 16 / `chapters/ch05-chengzhi-shengfu.md` 论胜复第二十五：木运少角，岁金清化来胜，则子火为复，反热化胜金。
  2. 查五行胜复论：木胜则金复以救土……五运之气犹权衡也，高者抑之，下者举之，化者应之，胜者复之。
  3. 结合论六病第二十八、论治法第三十：六气为病与「必先岁气，无伐天和；资取化源」之治则。
- **用途**：把「气化失衡—自稳—病机—治法」串成闭环，纯文献研读，理解本书独有纵深。

## 反模式（禁止）
- ❌ 用本 skill 给「我今年什么运、该吃什么方、用多少量、是什么体质」之类个性化建议。
- ❌ 自行推算剂量、自行加减、自行合用运气方。
- ❌ 把岁运太过不及、天符岁会、南北政、胜复／五郁／六病／六脉当作自诊自疗或算命宿命依据。
- ❌ 以本书机制文字（尤其「亢害承制／胜复／五郁／六病」）直接作为自疗指南。
- ❌ 以本 skill 替代执业中医师面诊。
