# 核心框架与心智模型

本书是明·张介宾（张景岳）《类经图翼》卷一「运气上」、卷二「运气下」的象数基础整理。卷一立太极—阴阳—五行生成数—气数之象数地基（景岳自谓「医道开卷第一义」）；卷二以「图翼」（图解 + 图说）展开五运六气推算全框架（化运、五音建运太少相生、主客运、正化对化、主客气、司天在泉、天符岁会、南北政脉不应）。它与《运气诸方》（三因）、《运气证治歌诀》（王旭高）、《医宗金鉴·运气要诀》**互补而非替代**：

| 层级 | 书名 | 资产 | 侧重 |
|------|------|------|------|
| **图翼·象数基础层（本书）** | 类经图翼·卷一·卷二「运气」（张介宾） | asset37 | 太极—阴阳—五行生成数—气数哲学地基 + 图翼推算细节（五音建运、南北政脉不应等深度） |
| 方源层 | 三因极一病证方论·卷五运气诸方（陈无择） | asset36 | 十六方药物组成、炮制分量、主治、煎服与随气加减（运气用方原方层） |
| 歌诀层 | 运气证治歌诀（王旭高） | asset34 | 以歌诀体重述十干运方与六支气方、六淫治例（运气证治方歌层） |
| 推算框架广度层 | 医宗金鉴·运气要诀（吴谦） | asset35 | 太极阴阳、五运六气推算、天符岁会、南北政体例广度（基本不载具体方剂） |

四书互补（象数基础 → 方源 → 歌诀 → 框架广度），**任何一书的研读都不可取代另外三书，更不可取代执业中医师面诊**：

1. **图翼·象数基础层（本书）**：补全医宗金鉴所缺的太极—阴阳—五行—气数根基，并加五音建运、南北政脉不应等深度推算细节。
2. **方源层（三因）**：把运气格局落到十六个原方，提供「用方」的文献源流。
3. **歌诀层（王旭高）**：把同一套运气治法编成方歌，便于记诵与证治对照。
4. **推算框架广度层（医宗金鉴）**：提供「按年干支推算运气格局」的全框架广度。

## 本书灵魂（务必先读）
- 太极—阴阳本源（卷一·太极图论，逐字）：**「太极本无极」**，**「太极动静而阴阳分」**。
- 五行生成数（卷一·五行生成数解，逐字）：**「天一生水，地六成之；地二生火，天七成之；天三生木，地八成之；地四生金，天九成之；天五生土，地十成之」**；**「太过者其数成，不及者其数生，土常以生也」**。
- 气数平准（卷一·气数统论，逐字）：**「至而至者和；至而不至，来气不及也；未至而至，来气有余也」**。
