# 术语表（类经图翼·卷一·卷二「运气」）

> 本章为术语的**学术定义**，供研读框架对照使用。定义以《内经》运气七篇与《类经图翼》明本底本用语为准；凡底本原文处均标注「底本原文」，凡属通行学术释义处标注「学术释义」。所有术语均仅作文献研读，不涉及任何临床诊断或用药建议。

## 太极 / 阴阳
- **底本原文（太极图论）**：太虚者，太极也，**太极本无极**，故曰太虚……**太极动静而阴阳分**。故天地只此动静，动静便是阴阳，阴阳便是太极，此外更无余事。
- **底本原文（阴阳体象）**：**阴阳者，天地之道也，万物之纪纲，变化之父母，生杀之本始，神明之府也。**
- **学术释义**：太极统摄理气阴阳，动静而分阴阳，为运气象数之最高本体。

## 五行生成数
- **底本原文**：**天一生水，地六成之；地二生火，天七成之；天三生木，地八成之；地四生金，天九成之；天五生土，地十成之**。岐伯曰：**太过者其数成，不及者其数生，土常以生也**。
- **学术释义**：河图定数，生数主内、成数配外；五太年应成数、五少年应生数，土恒用生数五，为岁运太过不及定数之根。

## 太过 / 不及 / 平气
- **底本原文（气数统论）**：运有余其至先，运不及其至后，非有余非不足，是谓平岁……**至而至者和；至而不至，来气不及也；未至而至，来气有余也**。又如太过被抑，不及得助，皆为平气。
- **学术释义**：阳干主太过、阴干主不及；气化早至/晚至为太过/不及之征，平气则「至当其时」。

## 五天五运
- **底本原文**：丹天之火气经于牛女壁奎，下临戊癸之方，此戊癸之所以为火运也……（黅天土/苍天木/素天金/玄天水类推）。五天歌：木苍危室柳鬼宿，火丹牛女璧奎边，土黅心尾轸角度，金素亢氐昴毕前，水玄张翼娄胃是，下为运气上经天。
- **学术释义**：太古望五天五气，下临十干之方而定五运化运（戊癸火/甲己土/丁壬木/乙庚金/丙辛水）。

## 五音建运 / 太少相生
- **底本原文**：土曰宫，金曰商，水曰羽，木曰角，火曰征……十干以甲丙戊庚壬为阳，乙丁己辛癸为阴，在阳则属太，在阴则属少。甲以阳土生乙之少商……癸以阴火复生甲之太宫。
- **学术释义**：十干阳太阴少，五音太少相生如环无端，主大运不离阴阳。

## 正化 / 对化
- **底本原文**：厥阴司巳亥，木生于亥，故正化于亥，对化于巳也……（少阴午/子、太阴未/丑、少阳寅/申、阳明酉/卯、太阳戌/辰类推）。一曰正司化令之实，对司化令之虚。
- **学术释义**：六气加十二支有正化（实、本、生数）与对化（虚、标、成数）之殊，以言阴阳衰盛合十二辰之动静消息。

## 主气 / 客气
- **底本原文（主气）**：主气者，地气也……厥阴木主初气……太阳寒水为终气……有常而无变者也。
- **底本原文（客气）**：客气者，天气也……分司天在泉左右四间之六气……加临于主气之上而为一岁之变化。
- **学术释义**：主气地气、守位常有；客气天气、动而不息，加临主气而生变。

## 司天 / 在泉
- **底本原文**：凡主岁者为司天，位当三之气；司天之下相对者为在泉，位当终之气……**岁半已前，天气主之；岁半已后，地气主之也。**
- **学术释义**：司天主上半年（三之气），在泉主下半年（终之气）；司天歌：子午少阴君火……巳亥厥阴风木主。

## 天符 / 岁会 / 太乙天符 / 同天符 / 同岁会
- **底本原文**：天符——中运同司天（12 年）；太乙天符——天符+岁会+岁支俱会（戊午乙酉己丑己未，4 年）；岁会——中运同岁支（8 年）；同天符——中运同阳年在泉（6 年）；同岁会——中运同阴年在泉（6 年）；合言六十年止 28 年。天符为执法，岁会为行令，太乙天符为贵人；中执法速危、中行令徐持、中贵人暴死。
- **学术释义**：气运相符之诸格，重叠统计后六十年共 28 年。

## 南北政 / 脉不应 / 阴阳交 / 尺寸反
- **底本原文（南北政）**：即用巳为南政，余为北政……南政寸上尺下、北政反之；司天应两尺，在泉应两寸。
- **底本原文（脉不应）**：北政之岁三阴在下则寸不应、在上则尺不应；南政之岁三阴在天则寸不应、在泉则尺不应……诸不应者，反其诊则见矣。
- **底本原文（阴阳交/尺寸反）**：阴阳交，交者死，惟辰戌丑未寅申巳亥八年有之；尺寸反，反者死，惟子午卯酉年有之；但本位当应而不应只是阴气不应、止疾，**不可胶柱**。
- **学术释义**：南北政以甲己（巳年）为南政象君，余象臣为北政；脉不应定上下沉细；阴阳交、尺寸反为危候，然须辨「交/反」方死，不可胶柱。

## 指掌法
- **底本原文**：记「厥、少太、少阳太」六字则六气尽矣；以巳亥为始起厥阴司天，子午为少、丑未为太，顺数到底皆其年分之司天。
- **学术释义**：以掌中六字推司天，简便记诵六气三阴三阳之序。
