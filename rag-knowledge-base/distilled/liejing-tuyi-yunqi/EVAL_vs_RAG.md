## 三、综合结论：互补，非替代

| 维度 | 蒸馏 skill（单书象数基础框架） | RAG（跨 68 部通用库） |
|------|--------------------------|----------------------|
| 聚焦度 | 《类经图翼》运气卷单书闭环（象数根基 + 图翼推算细节一体） | 跨文献，返回多条混杂（病机/方剂/体质/医案） |
| 结构化映射 | cheatsheet/patterns 直接给「生成数/化运/相生链/主客运/正对化/司天/天符/南北政」表，秒答 | 需从多条 entry 中人工挑目标 |
| 原文形态 | 保留明本象数/图翼逐字原文 | 现代化摘要，无原解逐字 |
| 临床/医案关联 | 弱（单书，不载临床加减/现代研究） | 强（能拉 asset1/2/4/5/10/14 病机、方剂、注家、医案 + source_quote 存证） |
| 安全 | 三件套强包裹（SKILL头 + cheatsheet 最高级 + ch07 最强） | 每条自动附免责声明 |
| 适合场景 | 通读/研读「这一本书」的象数基础与图翼推算 | 跨书查证某格局病机/某注家/某医案 |

**建议**：RAG 管「临床断言的出处与跨书查证」，蒸馏 skill 管「单书象数基础通读效率」，二者并存。前者为本项目既有能力，后者作为 `literature/` 的「图翼·象数基础层」补充——与既有《运气诸方》（方源层，asset36）、《运气证治歌诀》（歌诀层，asset34）、《医宗金鉴·运气要诀》（推算框架广度层，asset35）共同构成运气学的「象数基础 + 方源 + 歌诀 + 框架」四研读层。
