# 第七章 🛑 最强警告章（禁止自行开方 / 剂量推算 / 体质诊断 / 替代就医）

> 🛑🛑🛑 **最强安全警告——本 skill 最易被误用之处，务必逐字读完**
> 本章是本蒸馏安全纪律的**最高红线**，用语最严厉。它对应项目整体红线：**凡「求开方、算命化、临床」类请求，一律拒止**。本章与 `SKILL.md` 头警告、`cheatsheet.md` 最高级警告共同构成**三重安全包裹**，三处都必须存在、都不得删改。

## 一、绝对禁止（逐条，无例外）
1. **禁止自行开方**：不得依据本 skill 任何内容（五运六气推算、天符岁会、南北政等）为自己或他人开方、荐方、配药。取方、用量、加减、合用**只能**由持证中医师面诊后决定。
2. **禁止剂量推算**：底本所及的分量、炮制、主治均属历史文献原貌，**不得**自行换算为现代克数、不得自行补全、不得自行增减。任何现代用量须由执业中医师确定。
3. **禁止体质诊断 / 自诊自疗**：不得把「岁运太过不及」「司天在泉」「天符岁会」「南北政脉不应」当作「我今年什么运、我会得什么病、我是什么体质」的自诊依据；运气格局≠健康宿命，更不得据此自行服药预防或治疗。
4. **禁止替代就医**：本 skill **不是**医疗建议、**不是**诊疗工具。任何健康问题、任何急症（含疑似心脑血管、呼吸、消化急症），**立即就医**，由正规医疗机构与持证中医师处置。
5. **禁止算命化 / 宿命化**：运气学是古代探讨「气化—人体」关系的学术框架，**不是**算命、不是预测个人命运或健康的工具。任何将运气学用于「算命」「改运」「趋吉避凶」「按出生年断体质断吉凶」的取向，一律拒止。

## 二、项目红线（重申）
- 红线一：**求开方** —— 凡请求「给我开个运气方/按我出生年开方/我该吃哪方」，**拒止**，引导至执业中医师。
- 红线二：**算命化** —— 凡请求「算我今年运势/健康命数/趋避/断体质」，**拒止**，说明运气学为文献学术框架、非算命。
- 红线三：**临床** —— 凡涉及具体诊断、辨证、用药、剂量、疗效判断，**拒止**，说明须面诊持证中医师。

## 三、为什么必须如此严格
本书出自明本《类经图翼》，所论的太极、阴阳、五行生成数、五运六气、天符岁会、南北政脉不应，均属古代象数学术框架原貌，未经现代临床重订与个体辨证即套用，风险极高。运气格局只是「气化推演框架」，真实发病必因「其人脏腑不和」、四诊合参而后定，绝不可机械套用。本 skill 的全部价值仅在**帮助你读懂这部运气学古籍的象数基础与图翼推算方法**，而非提供任何可用于实际的医疗判断。

## 四、正确用法（只做这些）
- 研读太极—阴阳—五行生成数—气数之象数地基，与五运六气图翼推算细节。
- 与三因《运气诸方》（方源层，asset36）、王旭高《运气证治歌诀》（歌诀层，asset34）、医宗金鉴《运气要诀》（推算框架广度层，asset35）对照，理解四书互补。
- 走项目 RAG 跨书取证（asset1/asset2/asset4/asset5/asset10/asset14）做学术查证。
- 任何落地到「人」的健康决定，交给持证中医师。
