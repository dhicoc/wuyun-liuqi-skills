# 研读 / 推算模式（可复用）

> 本节归纳本蒸馏可复用的「研读式」模式。模式仅用于**文献框架对照与象数/推算溯源**，所有取方、用量、加减、合用、体质判断均须由执业中医师面诊后决定，本 skill 不输出任何实际处方或个性化建议。

## 模式 1：象数 → 推算衔接（图翼细节补足）
- **输入**：某年干支（如「甲己」）。
- **步骤**：
  1. 查 `cheatsheet.md` 表 3（五天五运下临化运表）：甲己 → 黅天下临 → **土运**。
  2. 查 `chapters/ch03-wuyun.md` 五天五运图解 / 月建夫妇化运三说，理解「为何甲己化土」（火生土之由）。
  3. 读法：通用推算（modules/yunqi-calc）给格局，本 skill 补「象数根基 + 图翼怎么解」，二者并观方见全貌。
- **用途**：从年干支直接落到五运化运之理，并补足通用推算缺的象数说明。

## 模式 2：图翼细节补足通用推算
- **通用推算轨**：用 `modules/yunqi-calc/` 与 `scripts/calculate_yunqi_api.py` 推当年岁运、司天在泉、天符岁会、南北政。
- **图翼补足轨（本书）**：再以本 skill 回查该格局对应的象数根基与图翼细节——五音太少相生链与初运太少（ch03）、主客运 73 日零 5 刻（ch03）、正化对化所司地支（ch04）、南北政上下与脉不应（ch06）。
- **用途**：「通用推算给格局 → 图翼补细节」闭环，专补医宗金鉴《运气要诀》（asset35）所缺的象数深度。

## 模式 3：四书多轨对照
- **图翼·象数基础层（本书，asset37）**：象数根基 + 图翼推算细节（五音建运、南北政脉不应）。
- **方源层（三因，asset36）**：十六方组成、炮制分量、主治、煎服、随气加减。
- **歌诀层（王旭高，asset34）**：十干运方、六支气方、六淫治例方歌。
- **推算框架广度层（医宗金鉴，asset35）**：太极阴阳、五运六气、天符岁会、南北政体例广度。
- **用途**：「框架推格局 → 图翼补象数 → 歌诀助记诵 → 方源取原方」四书互补闭环；再走 RAG（asset1/2/4/5/10/14）补跨书病机与医案。

## 模式 4：五音太少相生链回查
- **输入**：某阳干/阴干（如「甲」）。
- **步骤**：查 `cheatsheet.md` 表 4（五音太少相生链）：甲太宫 → 乙少商 → 丙太羽 → …… → 癸少征 → 复甲太宫，如环无端。结合主运图说推初运太少（阳太阴少）。
- **用途**：理解「大运不离于阴阳，主客不离于大运」，纯文献研读。

## 反模式（禁止）
- ❌ 用本 skill 给「我今年什么运、该吃什么方、用多少量、是什么体质」之类个性化建议。
- ❌ 自行推算剂量、自行加减、自行合用运气方。
- ❌ 把岁运太过不及、天符岁会、南北政当作自诊自疗或算命宿命依据。
- ❌ 以本 skill 替代执业中医师面诊。

> 所有模式仅供文献研读与学术框架对照，禁止据此自行用药，须咨询执业中医师。
