# 第八章 研读 / 取用指引

> 本章为「如何研读、如何按年干支溯源取方、如何跨书对照、如何走 RAG 取证」的方法指引。**本章不含、也不输出任何实际处方或个性化用药建议**；任何取方、用量、加减、合用均须由执业中医师面诊后决定。
> 任何临床/剂量/诊断内容仅供文献研读，禁止据此自行用药，须咨询执业中医师。

## 一、如何按年份取方（天干→运方、地支→气方）
1. 取某年干支（如「壬寅」）。
2. **天干 → 运方**：壬（阳木）→ 木运太过（发生之纪，先天）→ 查 `cheatsheet.md` 表1 / `chapters/ch02-wuyun-shiyifang.md` → **苓术汤**。
3. **地支 → 气方**：寅（少阳相火司天 / 厥阴风木在泉，先天）→ 查 `cheatsheet.md` 表2 / `chapters/ch03-liuqi-siyifang.md` → **升明汤**。
4. 读法：岁运方言「太过/不及所胜」，岁气方言「司天在泉所主」，二者并观，方见当年用方全貌（壬寅年即「苓术汤 + 升明汤」两套并存对照，纯文献溯源，非合用建议）。

### 其他举例（纯取方溯源，非处方）
- 甲子年：甲 → 土运太过（敦阜）→ 附子山茱萸汤；子 → 少阴君火司天 / 阳明燥金在泉（先天）→ 正阳汤。
- 己亥年：己 → 土运不及（卑监）→ 白术厚朴汤；亥 → 厥阴风木司天 / 少阳相火在泉（后天）→ 敷和汤。
- 丙申年：丙 → 水运太过（流衍）→ 川连茯苓汤；申 → 少阳相火司天 / 厥阴风木在泉（先天）→ 升明汤。

## 二、如何与王旭高 / 医宗金鉴对照（三书互补）
- **推算框架（医宗金鉴）**：先据年干支推「运 / 司天在泉 / 天符岁会 / 南北政 / 五脏病机」（见本项目 `yizong-jinjian-yunqi-yaojue` skill）。
- **方源（本书）**：以推得格局回查对应十六方之组成、炮制、分量、主治、煎服、随气加减（ch02/ch03）。
- **歌诀（王旭高）**：把同一套运方/气方编为方歌，助记诵、明证治（见本项目 `yunqi-zhengzhi-gejue` skill）。
- 三者关系与研读次序见 `chapters/ch06-yuanliu.md`。

## 三、如何走 RAG 跨书取证
本 skill 是《三因》卷五十六方**单书深度方源框架**；项目既有 RAG（`scripts/rag_search.py`）是**跨 68 部文献**的通用取证库。两者互补，非替代。

- **用本 skill 当**：问题聚焦「这一本书」的方源 / 组成 / 主治 / 岁运归属 / 司天在泉归属。
- **调 `rag_search.py` 当**：需要跨书原文出处、岁运病机现代化解读、临床医案佐证 —— 对应资产：
  - `asset1`（岁运病机）、`asset2`（司天在泉）、`asset4`（方剂）、`asset10`（治法）、`asset14`（医案）。
- **调用形态**：`rag_search --key 「rag_key」` 或 `--asset 「资产」`。例如答「卯酉年用何方、主什么病」：本 skill 给审平汤原文（ch03），RAG 拉出 asset2 的司天在泉病机与 asset14 医案佐证。
