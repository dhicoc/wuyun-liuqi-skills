# 第六章 源流与三书互补定位

> 本章为学术源流定位，供研读框架对照。源流叙述本于底本卷五「源流定位」段（属学术说明，非原文方剂），并结合运气学史通行认知。

## 一、陈无择十六方为运气用方经典源流（学术释义）
陈无择《三因极一病证方论》卷五此十六方（五运十方 + 六气六岁方），为后世「运气用方」之经典源流。其特色在：依《内经》运气七篇，将岁运（十干）与司天在泉（六支）各立专方，方后载明组成、炮制、分量、主治、煎服与随主气加减，使「运气推算」直接落到「用方」——此即本书作为「方源层」的根本价值。

金元以降诸家皆本于此：
- 明代王旭高《运气证治歌诀》以歌诀体重述十干运方与六支气方、六淫治例，便于记诵与证治对照（**歌诀层**）。
- 清代《医宗金鉴·运气要诀》（吴谦等编纂）重「推算框架」：太极阴阳、五行生克、五运六气、天符岁会、南北政、运气为病，基本不载具体方剂（**推算框架层**）。

## 二、三书互补，非替代
| 层级 | 代表书 | 重心 | 价值 |
|------|--------|------|------|
| 方源层 | 本书（陈无择《三因》卷五） | 十六方组成/炮制/分量/主治/煎服/加减 + 岁运/司天在泉归属 | 运气用方之「原方」 |
| 歌诀层 | 王旭高《运气证治歌诀》 | 十干运方、六支气方、六淫治例之方歌 | 记诵与证治对照 |
| 推算框架层 | 《医宗金鉴·运气要诀》 | 五运六气推算、天符岁会、南北政、运气为病 | 按年干支推运气格局 |

三者关系：**方源 → 歌诀 → 框架**，各司其职、互相印证，不得相互替代，更不得任一层单独作为临床依据。

## 三、研读建议（先框架 → 再方源 → 再歌诀对照）
1. **先读框架**：以《医宗金鉴·运气要诀》建立「年干支 → 运/气 → 司天在泉 → 五脏病机」的推算框架，理解当年运气格局。
2. **再读方源**：以本书（陈无择）回查该格局对应的十六方——组成、炮制、分量、主治、煎服、随气加减，得「原方」全貌（见 `chapters/ch02-wuyun-shiyifang.md`、`chapters/ch03-liuqi-siyifang.md`）。
3. **歌诀对照**：以王旭高《运气证治歌诀》把同一套运方/气方编为方歌，助记诵、明证治。
4. **跨书取证**：凡需岁运病机现代化解读、临床医案佐证，走项目 RAG（`rag_search.py`，asset1/asset2/asset4/asset10/asset14），详见 `chapters/ch08-shiyong-zhinan.md`。
