## 三、综合结论：互补，非替代

| 维度 | 蒸馏 skill（单书方源框架） | RAG（跨 68 部通用库） |
|------|--------------------------|----------------------|
| 聚焦度 | 《三因》卷五十六方单书闭环（运方 + 气方 + 组成 + 主治 + 煎服 + 加减一体） | 跨文献，返回多条混杂（病机/方剂/体质/医案） |
| 结构化映射 | cheatsheet/patterns 直接给「天干→运方」「地支→气方」「司天→方」「在泉→方」表，秒答 | 需从多条 entry 中人工挑目标 |
| 原文形态 | 保留宋本组成/分量/煎服/加减逐字原文 | 现代化摘要，无原方逐字 |
| 临床/医案关联 | 弱（单书，不载临床加减/现代研究） | 强（能拉 asset4 现代化方剂研究 + asset14 真实医案 + source_quote 存证） |
| 安全 | 三件套强包裹（SKILL头 + cheatsheet 最高级 + ch07 最强） | 每条自动附免责声明 |
| 适合场景 | 通读/研读「这一本书」的运气用方方源 | 跨书查证某方出处/某格局病机/某医案 |

**建议**：RAG 管「临床断言的出处与跨书查证」，蒸馏 skill 管「单书方源通读效率」，二者并存。前者为本项目既有能力，后者作为 `literature/` 的「方源研读层」补充——与既有《运气证治歌诀》（歌诀层）、《医宗金鉴·运气要诀》（推算框架层）共同构成运气学的「方源 + 歌诀 + 框架」三研读层。
