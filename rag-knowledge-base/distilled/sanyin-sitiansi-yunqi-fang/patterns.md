# 研读 / 取方模式（可复用）

> 本节归纳本蒸馏可复用的「研读式」模式。模式仅用于**文献框架对照与取方溯源**，所有取方、用量、加减、合用均须由执业中医师面诊后决定，本 skill 不输出任何实际处方或个性化建议。

## 模式 1：按干支取方（方源回查）
- **输入**：某年干支（如「壬寅」）。
- **步骤**：
  1. 取天干 → 查 `cheatsheet.md` 表 1（天干→运方）：壬 → 木运太过（发生）→ **苓术汤**。
  2. 取地支 → 查 `cheatsheet.md` 表 2（地支岁→气方）：寅 → 少阳相火司天/厥阴风木在泉 → **升明汤**。
  3. 读法：岁运方言「太过/不及所胜」，岁气方言「司天在泉所主」，二者并观，方见当年用方全貌（详见 `chapters/ch08-shiyong-zhinan.md`）。
- **用途**：从年干支直接落到十六方中的「运方 + 气方」两套，便于原方对照。

## 模式 2：推算 + 用方 双轨
- **推算轨**：先用《医宗金鉴·运气要诀》框架（天干→运、地支→司天在泉、天符岁会、南北政）推当年运气格局与五脏病机。
- **用方轨**：再以本 skill（方源层）回查该格局对应的十六方组成、主治、煎服、随气加减。
- **歌诀轨（衔接）**：王旭高《运气证治歌诀》把同一套运方/气方编为方歌，用于记诵与证治对照。
- **用途**：「框架推格局 → 方源取原方 → 歌诀助记诵」三书互补闭环。

## 模式 3：随主气加减回查
- **输入**：某气方 + 当年节气区间（如「审平汤，自大寒至春分」）。
- **步骤**：查 `chapters/ch05-zhifa-fanli.md` 中各气方随主气加减法汇编（逐字照底本），按六步主气时段取对应加减。
- **用途**：理解陈无择「随时气加减、四畏无犯」的用方精神，纯文献研读。

## 模式 4：运太过 → 受邪脏 → 方 映射
- **底本依据**：岁运十方各载明「岁某太过/不及……某脏受邪」（如木太过→脾土受邪→苓术汤）。
- **用途**：把「岁运太过不及」与其「所胜受邪之脏 + 对治之方」串成一条线，便于与《医宗金鉴》运气为病五藏归属框架对照（跨书取证走 RAG 之 asset1/asset2）。

## 反模式（禁止）
- ❌ 用本 skill 给「我今年该吃什么方、吃多少」之类个性化用药建议。
- ❌ 自行推算剂量、自行加减、自行合用十六方。
- ❌ 把时气病等同于普通感冒自行按方处理，或等同于疫疠自行预防用药。
- ❌ 以本 skill 替代执业中医师面诊。

> 所有模式仅供文献研读与学术框架对照，禁止据此自行用药，须咨询执业中医师。
