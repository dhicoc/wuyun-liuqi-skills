# 核心框架与心智模型

本书是宋·陈言（陈无择）《三因极一病证方论》卷之五的方源整理。陈无择依《内经》运气七篇，将「岁运太过不及」与「司天在泉六气」各立专方，共十六方（五运十方 + 六气六岁方），为后世「运气用方」之滥觞。它与《运气证治歌诀》（王旭高）、《医宗金鉴·运气要诀》（吴谦）**互补而非替代**：

- **本书（陈无择本）**：重「方源」——十六方的药物组成 + 炮制分量 + 主治 + 岁运/司天在泉归属，是运气用方的「原方层」。
- **王旭高本**：重「歌诀」——以歌诀体重述十干运方与六支气方、六淫治例，是运气证治的「方歌层」。
- **医宗金鉴本（吴谦）**：重「推算框架」——太极阴阳、五运六气推算、天符岁会、南北政，是运气体例的「推算框架层」。它基本不载具体方剂。

三层互补（方源 → 歌诀 → 框架）：

1. **方源层（本书）**：十六方原文（药物组成、炮制、分量、主治、煎服、随气加减）。
2. **歌诀层（王旭高）**：把方源编成方歌，便于记诵与证治对照。
3. **推算框架层（医宗金鉴）**：提供「按年干支推算运气格局」的全框架，落点到五脏病机。

## 本书灵魂（务必先读）
- 卷五岁运总纲：**「凡六壬、六戊、六甲、六庚、六丙岁，乃木火土金水太过，五运先天；六丁、六癸、六己、六乙、六辛岁，乃木火土金水不及，为五运后天，民病所感。治之，各以五味所胜调和，以平为期。」**
- 六气凡例**「四畏」**（ch05 全文照底本）：**「司气以热，用热无犯；司气以寒，用寒无犯；司气以凉，用凉无犯；司气以温，用温无犯……是谓四畏。」**——用方须顺司气之寒热温凉，不可妄犯，是运气用方的第一红线。

## 与 RAG 协作指引（何时用本 skill，何时调 rag_search）
本 skill 是《三因》卷五十六方**单书的深度方源框架**；项目既有 RAG（`scripts/rag_search.py`）是**跨 68 部文献**的通用取证库。两者互补，非替代：

- **用本 skill（蒸馏框架）当**：问题聚焦「这一本书」的方源 / 组成 / 主治 / 岁运归属 / 司天在泉归属 —— 如「壬年用哪方、组成是什么」「辰戌年司天在泉与方名」「六气方随主气怎么加减」。

  - `asset1`（岁运病机）、`asset2`（司天在泉）、`asset4`（方剂）、`asset10`（治法）、`asset14`（医案）。
- **最佳实践**：先读本 skill 的方源框架（1 跳查表 `cheatsheet.md` / `patterns.md`），再用 `rag_search --key 「rag_key」` 或 `--asset 「资产」` 补「原文出处 + 真实医案」。例如答「卯酉年用何方、主什么病」：本 skill 给审平汤原文（ch03），RAG 拉出 asset2 的司天在泉病机与 asset14 医案佐证。
