# 术语表（三因极一病证方论·卷五运气诸方）

> 本章为术语的**学术定义**，供研读框架对照使用。定义以《内经》运气七篇与《三因》卷五底本用语为准；凡底本原文处均标注「底本原文」，凡属通行学术释义处标注「学术释义」。所有术语均仅作文献研读，不涉及任何临床诊断或用药建议。

## 时气（时气病 / 时行）
- **底本原文**：本书分篇为「五运时气民病证治」「六气时行民病证治」，方后主治多云「治……岁……民病……」。
- **学术释义**：指因当年岁运、司天在泉之乖戾乖常而感生之病证，属「因时令之气致病」。在《三因》语境中，时气病是「运气体质 + 岁气偏胜」框架下的群体性、时令性发病，**既不等同于普通感冒（伤风），也不同于疫疠（大流行、传染特甚者）**。底本各篇强调「民病」，即岁气所向、民多感之，而非个别人之普通外感。

## 太过 / 不及
- **底本原文**：「六壬、六戊、六甲、六庚、六丙岁，乃木火土金水太过……；六丁、六癸、六己、六乙、六辛岁，乃木火土金水不及。」
- **学术释义**：岁运（中运）之盛衰。阳干（壬戊甲庚丙）主太过，运气体强、所胜之脏受邪偏甚；阴干（丁癸己乙辛）主不及，运气体弱、所不胜乘之。太过称「先天」（气化运行先天），不及称「后天」（气化运行后天）。

## 司天 / 在泉
- **底本原文**：六气凡例「岁半之前，自大寒后，天气主之；岁半之后，自大暑之后，地气主之；上下交互，气交主之。」
- **学术释义**：司天为岁半（上半年，大寒后至大暑前）主气之天（客气第三步，位当司天）；在泉为岁半之后（下半年）主气之地（客气第六步）。本书六气六岁方每岁统「司天 + 在泉」二气立治。如辰戌岁太阳寒水司天、太阴湿土在泉。

## 先天 / 后天
- **底本原文**：五运「太过……五运先天；不及……为五运后天」；六气方各标注「气化运行先天 / 后天」。
- **学术释义**：气化早至为先天（太过之纪多见），气化晚至为后天（不及之纪多见）。陈无择以此标示当年气化之常变，为用方之背景。

## 四畏
- **底本原文**：「司气以热，用热无犯；司气以寒，用寒无犯；司气以凉，用凉无犯；司气以温，用温无犯。司气同其主，亦无犯；异主，则少犯之，是谓四畏。若天气反时，可依时，及胜其主，则可犯，以平为期，不可过也。」
- **学术释义**：运气用方第一红线——用药之寒热温凉，须顺「司气」之性，不可妄犯。司气与主治同气则无犯；异气则少犯。惟「天气反时」（气候反常）方可依时、胜其主而犯之，但仍以平为期、不可过。详见 `chapters/ch05-zhifa-fanli.md`。

## 锉散
- **底本原文**：十六方煎服法皆首云「上锉散。每服四钱……煎七分，去滓，食前服。」
- **学术释义**：宋制饮片制法。「锉」即切碎，「散」此处指切碎后入煎之粗散（非冲服散剂），每服以水一盏半煎至七分，去滓食前温服。本方源中「锉散」为统一煎服体例。

## 五味所胜
- **底本原文**：「治之，各以五味所胜调和，以平为期。」
- **学术释义**：据《内经》五味偏胜、以所胜之味制岁气之偏，求得平和，是陈无择十六方组方之总纲。
