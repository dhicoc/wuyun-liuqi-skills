# RAG 引文溯源与逐字合规政策（Grounding Policy）

本文件声明 `rag-knowledge-base/` 下各资产 `source_quote` 引文的溯源规则、已知历史债的处置，
以及「跨版本引文」的显式声明与复核机制。

## 1. 逐字合规底线

每条 `source_quote` 必须是其 `source`（书名·章节）对应 `literature/*.md` 的**精确字符子串**：

- 保留源文原繁体 / 原简体，不简化、不意译、不翻译；
- 不含 `'''` 包裹符、`【】` 标记、全角空格等人工分隔符；
- 与 digitized `.md` 的字符（含标点、换行）完全一致。

> 注：`validate_knowledge_base.py` 仅校验结构与可检索键，不校验逐字子串关系；
> 逐字校验由独立审计脚本完成（见第 4 节）。

## 2. 真债（源被重编辑）已修复

一类历史债源于「源文献 `.md` 后来被重编辑」（如插入 `'''`、加 `【王】`/年龄标记、加全角空格、
部分跳句），导致旧 `source_quote` 不再是逐字子串。此类债与 asset20 吴鞠通医案同源。

| 资产 | 书名 | 已修条数 | entry_id |
|---|---|---|---|
| asset17 | 松峰说疫 | 7 | wuyu_zhifa_01/02、shishou_yi_02/03/07/10/11 |
| asset30 | 立斋外科发挥 | 14 | lz_001/002/006/007/026/035/044/058/073/076/093/094/097/108 |

**修复方法**：去 `'''`/`【】`/全角空格/空白后取最长公共子串（LCS），回映原始位置，
抽取源文原生逐字片段。修复后全 21 条经独立复验均为源 `.md` 精确子串（0 失败）。

## 3. 跨版本引文（显式声明，非债）

审计发现另有 **1125 条** `source_quote` 不构成当前 digitized `.md` 的逐字子串。经人工抽样核对，
这些**不是伪造或改写**，而是**版本差异**：

- 各书 digitized `.md` 仅是某一版本（常为四库传统本或某批节选），而引文多取自
  **现代校注 / 排印本 / 另一批节选**，措辞、标点、换行存在异文；
- 例：asset26 杏轩 xx_002 引文头「病由先天不足，心脾内亏所致」命中 `.md`，仅尾部异文；
  asset27 孙文垣 swy_001/002 含该书特有具体医案、药名、剂量，取自未被收录的另一版本。

**显式声明**：上述 1125 条均已在条目上加 `grounding` 字段标记：

```json
"grounding": "cross-edition"
```

含义：合法跨版本引文，非伪造、非改写；其真实性由「版本差异」解释，不强制 re-ground 到当前 `.md`
（强行改成子串反而可能劣化到残缺 / 他版）。

## 4. 复核机制（用户质疑时）

若读者或用户质疑某条引文的真实性，**可令 AI agent 联网检索该书的权威版本进行复核**：

1. 依据条目 `source`（书名·章节）与 `entry_id` 定位待核引文；
2. AI agent 联网检索该书权威善本 / 影印本 / 校注本（如书格、古籍馆、各大图书馆数字善本、
   专业中医古籍数据库等）；
3. 比对引文与原版，给出「一致 / 版本异文 / 存疑」判定，并附出处链接；
4. 若确属错误引文，再走第 2 节同法修复。

复验可由以下脚本复现（审计口径）：

```bash
python - <<'PY'
# 取全部 grounding=="cross-edition" 的条目与全部非逐字条目清单
import json, glob
for fp in sorted(glob.glob("rag-knowledge-base/asset*.json")):
    d = json.load(open(fp, encoding="utf-8"))
    for e in (d if isinstance(d,list) else d.get("entries",[])):
        if e.get("grounding") == "cross-edition":
            ...  # 该条为已声明的跨版本引文
PY
```

## 5. 处置结论（务实派 / 方案 C）

- ✅ 21 条 reedit 真债：已修复为逐字子串，本地提交。
- ✅ 1125 条跨版本引文：显式声明（`grounding: "cross-edition"`），保持其合法性与可读性，不强行 re-ground。
- ⏸️ 不采取「严格派」（全量 re-ground 到当前 `.md`）与「正解派」（补全权威善本后再 re-ground），
  以免劣化或产生过大工程；如需推进任一方向，另开一轮。
