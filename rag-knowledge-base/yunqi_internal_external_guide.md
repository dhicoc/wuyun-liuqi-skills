# 内外联动指南 — 内因病机 → 外候医案检索

> 本文件打通「**内因病机 → 外部症候（外证/外科）**」的联动检索链。
> 中医外科之证"必根于其内"（陈实功语）：肝郁化火→瘰疬乳癖、湿热内蕴→疔疮痈肿、
> 肾精耗竭→脱疽骨败、气血亏虚→疮疡难敛。Agent 需由内因推外候、由外证溯内因，
> 内外同治。
>
> 联动检索：内因 key 精确命中 asset29 的 `internal_key` 字段 → 召回外候医案。
> 检索命令：`python scripts/rag_search.py --key <internal_key> --asset asset29`

## 三、Agent 使用规则

1. **先辨内因**：推算/辨证得出脏腑气血病机（肝火/湿热/肾虚/气虚等）后，
   用第五节对照表找出对应 `internal_key`。
2. **外候召回**：`rag_search --key <internal_key> --asset asset29` 召回外候医案，
   观察该内因在临床上显于哪些外证。
3. **内外同治**：参考医案的"内服方（治内因）+ 外治方（消外候）"组合，
   如脱疽 wk_001：内服托里消毒散 + 外灸蟾酥饼贴。
4. **反向溯源**：用户报外部症候（痈肿/瘰疬/脱疽）时，由 asset29 反查其
   `internal_cause` 字段，说明外证之内因，附内服调理方向。
5. **辨死证**：肾水竭、元气内败之疔疮脱疽（wk_008/wk_009、lz_001），
   source_quote 明确辨不治，Agent 须如实告知预后，不妄施攻伐。
6. **薛己气血观**（asset30）：痈疽不起发/不溃腐/不收敛/脓少清，皆气血虚宜大补，
   最忌攻伐。内因气血虚实直接决定外候起发溃脓收敛。
6. 涉及外用药物/针刺艾灸，须附加免责声明（外治法亦属医疗行为）。
