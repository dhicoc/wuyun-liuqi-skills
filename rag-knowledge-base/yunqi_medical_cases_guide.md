# 医案库 × 运气病证检索指南

> 本文件是**医案库（asset9 / asset11-32）的 Agent 检索导航**。
> Agent 无需调用任何脚本，用 Grep/Read 本指南即可确定「当前运气语境下该查哪个医案库」。
>
> 目的：打通「运气推算 → 病证 → 医案佐证」的检索链。
> 医案库按病证关键词检索（`rag_search --asset <库> <病证>` 或 `rag_search <病证> --asset <库>`），
> 与推算引擎的 rag_key（asset1/2/3/9/17）形成互补：**病机与治则查 asset1-3，同格局岁图查 asset9，
> 运气瘟疫专方查 asset17，历代名家临证验案查 asset11-26**。

## 一、检索优先级（遇到用户问题先看这里）

| 用户问 | 先查 | 再查 | 说明 |
|--------|------|------|------|
| 某年/某日运气格局、病机、治则 | `asset1-3`（rag_key 精确） | `asset4-7`（方/注家/地域/体质） | 核心推理层，必查 |
| 同格局往年怎么治（岁图医案） | `asset9`（`--key <suiyun/sitian/zaiquan>`) | — | 与推算 rag_key 直接对接 |
| 某运气格局对应的瘟疫防治 | `asset17`（`--key water_excess` 等） | — | 松峰说疫·运气瘟疫，唯一直接对接运气的医案库 |
| 某病证的历代名家验案 | 按下方**病证路由表**选库 | 全库模糊检索 | 佐证层，按病证关键词 |

**关键原则**：医案库（asset11-26）只按**病证关键词**检索，不按运气 rag_key 检索。
推算引擎的 rag_keys（如 `water_excess`）不会自动命中它们——需由 Agent 将运气病机**翻译成病证**后再检索。
翻译示例：
- `water_excess`（水运太过，寒水偏盛）→ 病证倾向：寒湿/霍乱/泄泻/水肿/痹痛
- `earth_excess`（土运太过，湿土偏盛）→ 湿温/泄泻/霍乱/肿胀/痰饮
- `shaoyin_junhuo_sitian`（少阴君火司天）→ 暑温/温热/血证/咳嗽
- `taiyin_shitu_sitian`（太阴湿土司天）→ 湿温/暑温/泄泻/痢疾

## 四、检索命令速查

```bash
# 按病证关键词检索（佐证层，最常用）
python scripts/rag_search.py 湿温 --asset asset18 --json
python scripts/rag_search.py 霍乱 --asset asset18 --json

# 按运气 rag_key 精确检索（仅 asset1-3/9/17 可用）
python scripts/rag_search.py --key water_excess --asset asset17 --json
python scripts/rag_search.py --key shaoyin_junhuo_sitian --asset asset9 --json

# 按日期综合召回（自动带出 asset1-3/4/7/9/10）
python scripts/rag_search.py --date 2026-06-29 --json

# 多库并查
python scripts/rag_search.py 湿温 --asset asset18 --asset asset19 --asset asset20 --json
```

## 六、使用规范（Agent 必读）

1. **核心推理查 asset1-3，佐证查医案库**——医案库回答"历代医家怎么治过"，不替代病机推理。
2. **先翻译后检索**——rag_key 不直接查医案库，先按第五节翻译成病证。
3. **首选库优先**——按第二节路由表先查首选库，不满足再补充库。
4. **白话转述**——检索到医案后，按 `prompts/system_prompt.md` 的医案白话转述要求：先白话转述病机/治法/转归，再附 source_quote 原文，注明出库。
5. **医案仅佐证**——须与本次运气推算结论互相印证或如实说明差异，不得代替本次辨证结论；涉及临床处方附加免责声明。
