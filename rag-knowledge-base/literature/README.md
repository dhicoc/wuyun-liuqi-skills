## 说明
- 每篇文献为独立 `.md` 文件，含 YAML 元数据（id / title / era / attribution / status / source）。
- `corpus.jsonl` 为可直接喂入嵌入模型的语料：每行一个 JSON `{id,title,era,attribution,status,text}`。
- 状态：`全文`=底本全文；`节录`=摘录相关段落；`说明`=序跋/解题类；`存目（原书已佚）`=原书失传仅存目录或辑佚说明；`存目（目录·摘编性质）`=现代整理汇编的目录性条目。
