# 五运六气文献库 · 检索说明

> 本目录是 35 篇公版五运六气文献原文的**零依赖基础层**。Agent 可直接 Grep+Read，不依赖任何脚本或向量模型。
>
> 共约 61.6 万字，覆盖先秦至清代。完整清单见 `README.md`（含编号/时代/状态/字数表）。

## 两层检索架构

| 层 | 方式 | 依赖 | 用途 |
|----|------|------|------|
| **基础层（本目录）** | Grep 关键词 → Read 段落 | 零 | Agent 直接阅读、引经据典 |
| **增强层（可选）** | bge-m3 向量语义检索 | 本地 Ollama | 口语化查询、语义相似召回 |

基础层始终可用。增强层需本地 `ollama pull bge-m3` + 建索引脚本（**不进仓库**，本地工具，仿 nihaixia 模式）。

## 基础层用法（Grep+Read，零依赖）

Agent 看到用户问题后，Grep 关键词定位文献，Read 对应段落：

| 用户问 | Grep 关键词 | 定位文件 |
|--------|------------|----------|
| 七篇大论某段原文 | 篇名或经文首句 | `黄帝内经·素问*.md`（7 篇） |
| 某年运气详查 | `甲子岁图` / `丙寅岁图` 等 | `圣济总录运气门*.md` |
| 王冰运气推演 | 玄珠密语相关词 | `玄珠密语*.md` |
| 运气疫病 | `刺法论` / `本病论` / `五疫` | `素问遗篇*.md` |
| 运气方药歌诀 | 方名或年份 | `运气证治歌诀*.md` / `三因方` 相关 |

## 增强层（可选，需本地 Ollama + bge-m3）

用 bge-m3 给 444 个段落建 1024 维向量索引，做语义检索。建索引脚本和向量文件**不进仓库**。如需启用：`ollama pull bge-m3` → 本地建索引脚本切分+嵌入 → `--search "口语查询"` 语义召回。

增强层适合"用户用大白话问、不知道精确关键词"的场景。精确检索仍走 Grep+Read 基础层。
