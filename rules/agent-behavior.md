# Agent 行为规则（R3–R5）

## 路由（R3）

- **MUST** 先读 `routing.yaml` 匹配任务，再进入子技能
- **MUST NOT** 跳过路由直接执行
- 意图模糊 -> `prompts/onboarding_prompt.md`
- 路由未命中 -> `routing.yaml` -> `on_miss`，不得强行匹配

## 知识层级（R5）

```text
推算层 -> 病机层 -> 临床层
文献层可随时穿插
```

- **MUST NOT** 无推算结果就断病机
- **MUST NOT** 无病机分析就给临床建议

## 防偷懒机制（Excuse Rebuttal Table）

Agent 常见偷懒模式及反驳，**出现以下念头时 MUST 按反驳执行**：

| 借口 | 反驳 |
|------|------|
| "凭记忆推算就行" | **MUST 调脚本**（`calculate_yunqi_api.py`），凭记忆推算违反 R2 |
| "不查医案直接编" | **MUST 调 `rag_search`**，无医案佐证不得断言疗效 |
| "这步可以跳过" | 禁止跳过，输出理由等用户确认 |
| "免责声明不用加" | 临床输出 **MUST** 附免责声明，违反 R1 |
| "用户可能不需要这个" | 永远不要替用户决定，给完整信息让用户选择 |
| "我已经知道怎么做了" | **先读文件**，可能含任务特定约束（routing.yaml/SKILL.md） |
| "任务基本完成了" | 完成 = 全部自检清单打勾（见 `routing-contract.md` 任务完成自检） |
| "知识库没有就告诉用户没有" | **先查经验库**（`field-journal/`），再 fallback 联网搜索 |
| "这个方子我直接写" | **MUST 标注"参考方药，须辨证加减"**，不得给具体剂量 |

## 自我监督（每 5 步自检）

每完成 5 次工具调用，暂停自检：
- **我在进步吗？** -- 是否逐步接近回答用户问题
- **重复了吗？** -- 是否在用相同参数反复调同一个工具
- **同一方法失败 2-3 次 -> MUST 换路**：
  - rag_search 0 命中 -> 换关键词或换 --field
  - 脚本报错 -> 检查参数格式，勿盲目重试
  - 推算结果异常 -> 交叉核对 calculate_yunqi_api 输出

## 任务闭环

非平凡任务结束前执行 `workflows/task-closure.md`（30 秒自检 + 可选沉淀）。

执行契约：`workflows/routing-contract.md`
