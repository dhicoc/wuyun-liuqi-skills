# 五味调和原则 (Five Flavors Balance)

## R — 原文 (Reading)

> 谨和五味,骨正筋柔,气血以流,腠理以密,如是则骨气以精。谨道如法,长有天命。阴之所生,本在五味;阴之五宫,伤在五味。是故多食咸则脉凝泣而变色,多食苦则皮槁而毛拔,多食辛则筋急而爪枯,多食酸则肉胝皱而唇揭,多食甘则骨痛而发落。
>
> — 《素问·生气通天论篇第三》/《素问·五藏生成篇第十》

---

## I — 方法论骨架 (Interpretation)

饮食不是简单的"吃饱吃好",而是一门精确的调配术。食物有五种基本味道——酸、苦、甘、辛、咸,
每种味道各有归入的脏腑:酸入肝、苦入心、甘入脾、辛入肺、咸入肾。适量则滋养对应脏腑,
过量则伤害该脏腑乃至其所克之脏。调和五味的关键不是"都吃一点"这种均摊法,
而是根据自身脏腑的虚实状态来增减:某脏偏虚则适当多食对应之味以补之,
某脏偏盛则减少对应之味以防过亢。同时要注意"五味所伤"——任何一味长期过量都有明确的病理后果。
这是一套以味觉为媒介的脏腑调节系统。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 五味过量的具体伤害
- **问题**: 偏食某一味会有什么后果
- **方法论的使用**: 素问逐一列举五味过量的伤害:多食咸→脉凝泣变色(伤血/心);多食苦→皮槁毛拔(伤肺);多食辛→筋急爪枯(伤肝);多食酸→肉胝皱唇揭(伤脾);多食甘→骨痛发落(伤肾)
- **结论**: 每种味道过量都有明确的脏腑伤害路径,味道偏好不是小事
- **结果**: 形成一套"五味→五伤"的对应体系,作为饮食警示

### 案例 2: 脏腑苦欲补泻的食疗方案
- **问题**: 特定脏腑出了问题应该吃什么味的食物
- **方法论的使用**: 藏气法时论给出"苦欲补泻"原则:肝苦急食甘以缓之,心苦缓食酸以收之,脾苦湿食苦以燥之,肺苦气上逆食苦以泄之,肾苦燥食辛以润之
- **结论**: 不是简单地"缺什么味补什么味",而是要根据脏腑的具体病态(急/缓/湿/逆/燥)来选择对应之味
- **结果**: 将饮食调节从笼统的"均衡"推进到精确的"对症调味"

### 案例 3: 压力大嗜甜的现象解释
- **问题**: 为什么有些人压力大时特别想吃甜食
- **方法论的使用**: 思虑过度伤脾(土),脾欲甘——身体本能地通过甜味来补脾。但多食甘则骨痛发落(甘入脾,土克水,过甘伤肾)
- **结论**: 嗜甜是身体自救的本能信号,但长期依赖甜食反而会伤害肾(骨骼和头发)
- **结果**: 解释了"用甜食减压→越吃越虚"的恶性循环机制

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 发现自己长期偏好某一种味道(如无辣不欢、嗜甜、极咸),想了解可能的健康影响
2. 需要制定日常饮食方案,希望从中医角度理解五味搭配
3. 出现某些身体症状,想知道是否与饮食偏好有关(如皮肤干燥与嗜苦、掉头发与嗜甜)
4. 想通过日常饮食调理某个脏腑(如肝不好该多吃什么味)

### 语言信号 (用户的话里出现这些就应激活)

- "我最近特别想吃XX味的食物"
- "饮食上怎么搭配比较健康"
- "我口味偏重/偏甜/偏辣,有没有问题"
- "XX脏腑不好,吃什么能调理"
- "总觉得吃什么都不香,味觉有点麻木"

### 与相邻 skill 的区分

- 与 `seasonal-regimen` 的区别: 四时调养是按**季节**全面调度起居运动情志,五味调和是按**味道偏好**调节饮食对脏腑的影响。两者在饮食维度有交集,但切入点不同——前者以季节为纲,后者以味道为纲。
- 与 `emotion-organ-proxy` 的区别: 情志脏腑模型是**从情绪推断脏腑状态**,五味调和是**从饮食味道推断脏腑状态**。两者都是脏腑分析的不同入口,但信号来源完全不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **评估当前五味摄入的偏向**
   - 完成标准: 已识别用户饮食中哪些味道偏多、哪些偏少,形成"五味摄入偏向图"(酸/苦/甘/辛/咸各占多少)

2. **对照五味归脏表找到影响**
   - 完成标准: 已将每种偏多/偏少的味道映射到对应脏腑(酸→肝、苦→心、甘→脾、辛→肺、咸→肾),并指出偏多之味可能造成的伤害(如咸多→脉凝泣,甘多→骨痛发落)

3. **调整到均衡并给出具体方案**
   - 完成标准: 已给出减少偏多之味、适当补充偏少之味的具体饮食建议,且方案考虑了用户的具体脏腑状态(有虚则补、有盛则减)。判停条件:若用户已有明确的脏腑诊断,直接跳到对症调味步骤

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 急性食物中毒或过敏反应(需要立即就医,不是调味问题)
- 已有专业营养师或医生制定的严格饮食方案(不要用五味框架覆盖专业方案)
- 用户有明确的代谢疾病(如糖尿病、肾病),特定味道对应的食物可能有禁忌

### 作者在书中警告的失败模式

- "谨和五味"容易被误解为五味等量摄入,实际上是根据脏腑虚实动态调配,不是均摊
- 只关注味道而忽视食物的寒热属性——同一种味道的食物可能寒热不同,效果也不同
- 用味道偏好替代医疗诊断:嗜咸不一定就是肾虚,五味只是辅助分析的维度之一

### 作者的盲点 / 时代局限

- 素问的五味分类基于古代食材,现代加工食品的"味"往往来自添加剂而非天然,其归脏效应是否一致存疑
- 五味归脏的对应关系基于经验归纳和五行推演,缺乏现代营养学的精确成分分析
- 现代人的饮食结构远比古人复杂,一个"咸"味可能对应完全不同的食物来源(海盐与酱油与味精)

### 容易混淆的邻近方法论

- "均衡饮食"的现代营养学建议关注的是**蛋白质/碳水/脂肪/维生素的比例**,五味调和关注的是**味道与脏腑的对应关系**,两者维度不同
- "食疗"通常指吃特定食物治特定病,五味调和是**日常饮食的长期平衡策略**,不是治疗手段
