# 五行生克网络思维

## R — 原文 (Reading)

> 五行者, 金木水火土也。更贵更贱, 以知死生, 以决成败, 而定五脏之气, 间甚之时,
> 死生之期也。
> 五脏受气于其所生, 传之于其所胜, 气舍于其所生, 死于其所不胜。
> 五脏相通, 移皆有次。五脏有病, 则各传其所胜。
>
> — 岐伯, 藏气法时论篇第二十二、玉机真藏论篇第十九

---

## I — 方法论骨架 (Interpretation)

五行生克网络思维是一套用于分析多要素系统中连锁效应的结构化方法。

其核心逻辑分为四层:

1. **要素归五行**: 将系统中的关键要素归入五类。每一类有其属性和功能。归类的标准不是表面相似, 而是功能角色——谁是生长的力量(木)、谁是驱动的力量(火)、谁是承载转化的力量(土)、谁是收敛规范的力量(金)、谁是蕴藏滋养的力量(水)。

2. **画生克关系图**: 五行之间存在两种基本关系——"生"(滋养、促进)和"克"(制约、抑制)。相生链条: 木生火、火生土、土生金、金生水、水生木, 构成正向循环。相克链条: 木克土、土克水、水克火、火克金、金克木, 构成制衡循环。

3. **沿链条推导**: 某一行的变化会沿相生链向下传导(母病及子), 也会沿相克链产生压力(乘——过度克制, 或侮——反克)。因此, 局部的变化可以推导出全局的连锁效应。

4. **找到关键干预点**: 连锁效应意味着"治一处牵全局"。干预的关键不是直接作用于症状所在的行, 而是找到链条上的关键节点——生链条上游(补母)或克链条的对立面。

这个框架的独特价值在于: 它把"事物相互影响"的模糊认知变成了一套可操作的关系图+推导规则。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 怒伤肝的连锁传导
- **问题**: 一个人长期愤怒(怒属木/肝), 除了肝脏本身, 还会影响什么?
- **方法论的使用**: 将"怒"归入木(肝)。沿相克链推导: 木克土, 肝气郁结会"乘脾"(过度克制脾/土), 导致消化问题——食欲不振、腹胀。沿相生链推导: 木生火, 肝气不舒可化火扰心, 出现失眠、心悸。
- **结论**: 一个情绪问题(怒)不只是局部问题, 会沿生克网络传导到消化(土)和心血管(火)两个子系统。
- **结果**: 治疗不能只治肝, 还要兼顾健脾(防木乘土)和清心(防木火扰心)。这就是"五脏相通, 移皆有次"的临床含义。

### 案例 2: 五脏传变预测
- **问题**: 肝脏有病, 接下来会如何发展?
- **方法论的使用**: "五脏受气于其所生, 传之于其所胜"——肝(木)受气于肾(水, 所生/母), 传之于脾(土, 所胜)。沿链条推导: 肝病→传脾(消化受影响)→若不治→继续传肾→最终至肺(金, 木所不胜之脏)而死。
- **结论**: 疾病不是静态的, 而是沿着五行生克链条有序传变。预测传变路径可以提前阻断。
- **结果**: "治未病"的具体操作之一——在疾病沿生克链条传到下一个脏腑之前, 先加固那个脏腑, 阻断传变。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **局部问题引发全局反应**: 某个部门/子系统出了问题, 用户担心会连锁影响其他部门/子系统, 需要预测传导路径。
2. **多要素交织的复杂问题**: 问题涉及5个左右的关键要素, 且要素之间存在支持(生)和制约(克)关系, 线性因果分析不够用。
3. **反复出现的循环问题**: 问题此起彼伏, 解决A又冒出B, 说明底层有一个循环机制在驱动, 需要画出关系图才能看清。

### 语言信号 (用户的话里出现这些就应激活)

- "动了A, B和C都跟着变了"
- "这个问题总是牵扯到好几个方面"
- "解决了这个, 那个又冒出来了"
- "它们之间好像有某种连锁反应"
- "只治局部不管用, 一停就复发"

### 与相邻 skill 的区分

- 与 `yin-yang-balance` 的区别: 阴阳平衡处理**两个对立面**的关系(二分法), 五行生克处理**五个(或多个)要素**的网络关系(多维互动)。要素多于两个时优先用五行。
- 与 `biao-ben-priority` 的区别: 标本缓急决定**优先级**(先做什么), 五行生克揭示**传导路径**(做了之后会怎样传导)。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **要素归五行: 将关键要素分类**
   - 列出系统中所有相关要素(目标5个左右), 根据其功能角色归入五行分类: 生长/启动(木)、驱动/活跃(火)、承载/转化(土)、收敛/规范(金)、蕴藏/滋养(水)。
   - 完成标准: 每个要素都已归入一个类别, 且归类理由清晰(不是随意贴标签)。

2. **画生克关系图: 建立要素间的互动关系**
   - 标出所有要素之间的"生"(促进/滋养)关系和"克"(制约/抑制)关系。画出完整的生克网络图。
   - 完成标准: 图中包含所有相生关系和相克关系, 且链条形成闭合循环(没有孤立的节点)。
   - 判停条件: 若要素少于3个, 无法形成有意义的网络, 建议改用 yin-yang-balance。

3. **沿链条推导: 预测连锁效应并找到干预点**
   - 从当前出问题的要素出发, 沿相生链和相克链分别推导: 会"生"出什么新问题? 会"克"到哪个要素? 反馈是否会回到起点形成循环? 然后确定干预点——在链条的哪个环节介入能阻断恶性传导。
   - 完成标准: 给出至少一条传导路径的推导, 以及一个具体的干预建议(作用于链条的哪个节点、预期效果)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **简单线性因果**: 如果问题是"A导致B", 一因一果, 没有连锁和反馈, 用五行生克是杀鸡用牛刀。
- **只有两个要素**: 五行网络至少需要三个要素才能形成链条。只有两个对立要素时, 应使用 yin-yang-balance。

### 作者在书中警告的失败模式

- **相乘与相侮的区分**: 克制过度叫"乘"(欺负), 是病理性的; 被克方反扑叫"侮"(反克), 也是病理性的。正常的克是制衡, 异常的乘和侮都会导致系统紊乱。不能把所有"克"关系都视为负面。
- **五脏有病则各传其所胜**: 疾病传变有确定方向, 不是随机扩散。忽略传变方向会导致"头痛医头脚痛医脚"——治了标处, 病已传到下一个脏腑。

### 作者的盲点 / 时代局限

- 素问的五行归类(五脏、五色、五味、五志等)是基于古代哲学和临床观察的归纳, 在现代应用中需要灵活转化。不是所有系统都能完美归入五行——如果要素恰好是4个或6个, 可以选取最关键的5个来分析。
- 五行框架侧重"均衡"和"循环", 对单方向的突变(如外力冲击导致系统瞬间崩溃)解释力有限。

### 容易混淆的邻近方法论

- **系统思考中的因果回路图**: 形式类似, 但五行生克提供了一套预设的关系类型(生/克)和推导规则(乘/侮/母病及子), 比自由绘制因果图更有结构。
- **SWOT分析**: 也是分类框架, 但SWOT只有4个静态类别, 没有五行生克之间的动态关系链条。
