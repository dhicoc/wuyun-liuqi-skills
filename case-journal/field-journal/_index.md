# 经验库索引

> 本文件记录 fallback 联网搜索沉淀的经验条目，按时间倒序排列。
>
> ⚠️ **经验库条目不是公版医案原文。**
> - 公版医案库（asset11-32，1994 条）：有 `source_quote` 原文存证，零编造
> - 经验库（field-journal）：Agent 联网搜索后的总结，可信度取决于来源质量
>
> **引用经验库条目时，MUST 标注置信度（高/中/低），且不得作为唯一依据。**

## 使用方法

1. 用户问题 -> 先查 `rag_search`（知识库，有原文存证）
2. 知识库命中 -> 直接使用，**无需查经验库**
3. 知识库未命中 -> 查本索引（经验库）
4. 经验库命中 -> 引用时 MUST 标注"经验库存档（非原文）" + 置信度
5. 仍未命中 -> 联网搜索 -> 沉淀新条目（含 source_quote + confidence）-> 更新本索引

## 置信度说明

| 置信度 | 含义 | 引用要求 |
|--------|------|----------|
| 高 | 来源为学术论文/官方教材/公版经典原文 | 可正常引用，标注来源 |
| 中 | 来源为专业中医网站/百科 | 引用时标注"待验证" |
| 低 | 来源为博客/自媒体/非专业平台 | 不建议直接引用，建议提示用户自行查证 |
