# 经验库索引

> 本文件记录 fallback 联网搜索沉淀的经验条目，按时间倒序排列。
> agent 回答问题前先查本索引，命中则直接引用，无需再次联网。

## 使用方法

1. 用户问题 -> 先查 `rag_search`（知识库）
2. 未命中 -> 查本索引（经验库）
3. 仍未命中 -> 联网搜索 -> 沉淀新条目到 `case-journal/field-journal/` -> 更新本索引
