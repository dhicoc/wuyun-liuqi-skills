## 四、Skill 架构实践

### 官方标准

- **Agent Skills 开放标准**：https://agentskills.io -- frontmatter 仅需 `name` + `description`
- **anthropics/skills** ⭐168k：https://github.com/anthropics/skills -- 官方仓库，含 spec + template
- **Claude Code Skills 文档**：https://code.claude.com/docs/en/skills

### 最佳实践对照

| 模式 | 说明 | 本项目 |
|------|------|--------|
| Map-first | SKILL.md 只做路由 | ✅ |
| Progressive Disclosure | frontmatter -> body -> references 按需加载 | ✅ |
| Single Source of Truth | 规则放共享 ref | ✅ routing.yaml |
| Worker Independence | 子技能独立可调 | ✅ modules/ |
| `${CLAUDE_SKILL_DIR}` 路径变量 | 跨安装路径可移植 | ❌ |
| skill 级 evals | 每个 skill 附 eval spec + golden cases | ❌ |
| `context: fork` 子 agent 隔离 | skill 在子 agent 运行 | ❌ |

## 五、关键结论

1. **本项目是唯一面向 AI Agent 的五运六气技能包**，同类项目均为传统 CLI/Web 应用
2. **最大差距是缺少 skill 级 evals**，官方标准要求每个 skill 附 eval spec + golden cases
3. **`kangarooking/huangdi-neijing-skill` 是直接互补项目**，可交叉引用形成完整能力栈
4. **学术界有大量「出生运气 × 疾病易感性」数据**，可新增 RAG asset
5. **齐化兼化/正化对化推算**需对照检查覆盖度
