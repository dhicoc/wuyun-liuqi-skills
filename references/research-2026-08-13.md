## 1. 结论速览

1. **「本包是唯一面向 AI Agent 的运气学技能包」论断仍然成立。** 外部生态在 2026 夏天明显转向**消费级 App / 商业 SaaS / 命理融合**，但没有任何一个开源项目做成「Agent 即装即用」的运气推算 skill。
2. **P10 关键修正**：HuggingFace `pokkoa/chinese-five-circuits-six-qi` **不是结构化运气表**，而是「干支年月 + 运气/命理/养生散文」的一列 `text`；且其许可证存在**歧义**（HF 页写「商业使用请联系授权」，第三方镜像标 CC BY 4.0）。→ P10 应「对齐 Parquet 容器格式」但**不要照搬其 schema、不要重分发其内容**。
3. **P12 可行性高**：`kangarooking/huangdi-neijing-skill`（22 个方法论 skill，MIT）结构清晰、可被 `npx skills add` 单装、SKILL.md 带 `related_skills` 组合关系 → 适合做**可选依赖 + 运行时桥接**，无需复制代码。
4. **P11 学术依据充分**：出生/胎孕运气 → 体质 → 疾病易感性 的关联有大量统计学研究支撑（符合率最高 79.1%、王琦九体 40 万+ 流调对应 313 病种）。这**正面验证了「激活而非扩数据」**——现有 asset33 的 earth/fire 维度应接进推理链，而非继续堆数据。

## 3. P10 情报：HuggingFace `pokkoa/chinese-five-circuits-six-qi`

**来源**：https://huggingface.co/datasets/pokkoa/chinese-five-circuits-six-qi （更新 2025-05-08）

### 3.1 实测事实

- **规模**：311 行，总大小 442 kB；下载量 ~29/月（小众）。
- **格式**：Parquet（`data/train-00000-of-00001.parquet`，HF `datasets` 标准）。
- **时间粒度**：年 + 月（干支年月，如「丙辰年庚寅月」）。
- **真实 schema（HF viewer）**：仅 **1 列 `text`**（字符串 710–2.77k 字符），每条是一段「五运六气 + 命理特征 + 个性 + 健康风险 + 养生建议」散文。**没有** 主气/客气/主克/主受 等结构化字段（第三方镜像描述的「含主气/客气」与实际 viewer 不符）。
- **许可证歧义（重要）**：
  - HF 数据集页脚：「© 2025 Pokkoa. **商业使用请联系团队获得授权支持**。」
  - 第三方镜像（selectdataset.com）标注：「数据集使用 **CC BY 4.0** 授权」。
  - 两者冲突 → **不能假定其可自由商用/重分发**。

### 3.2 对 P10 的可执行建议

- ✅ **对齐 Parquet 容器格式**（`generate_rag_index.py --format parquet`），这是 HF `datasets` 生态的事实标准，ML 研究者可直接 `load_dataset` 消费。
- ❌ **不要照搬其 schema**：它是散文单列，无结构化运气字段。我们的导出应保留**自有结构化字段**（`year`/`ganzhi`/`sui_yun`/`si_tian`/`zai_quan`/`zhu_qi`/`yun_qi_xiang_he`/`rag_key`/`source_quote`/`disease` 等），比 pokkoa 更有分析价值。
- ❌ **不要重分发 pokkoa 内容**：许可证歧义，且我们自有 1994 条医案 + asset33 数据，无需借其内容。
- 💡 **增值点**：可额外生成「year+month 粒度、宽年份跨度」的结构化运气 Parquet（pokkoa 只有 311 条散文），对 ML 时序建模真正有用；导出时附 README 说明字段含义与许可（我们自身数据按本包 LICENSE）。
- 💡 **互引而非复制**：导出文档可注明「同类公开数据集：pokkoa/chinese-five-circuits-six-qi（散文型，许可需授权）」，作为对照引用。

## 5. P11 情报：体质 / 易感性「激活」的文献依据

**核心命题**：asset33 的 earth/fire 维度「存在但零查询」→ 正确做法是把「出生/胎孕运气 → 体质 → 疾病易感性」链路接进推理链，而非扩库。以下证据支持该方向。

### 5.1 运气 → 体质 关联（统计学，非玄学）

- **宋昊撅**：主气对体质影响更明显；**同天符之年形成平和质概率更大**。
- **张维骏**等：胎孕期五运特点对应的发病倾向，与实际所患疾病**符合率 79.1%**。
- **张轩**等：先天五运六气源自**天符等不平和年**者，后天易罹五脏病；源自**岁会等平和年**者不易；「**土**」在先天及发病运气中多次出现 → 土运之年注意防五脏病。
- **刘一玄**等：出生干支运气对后天**心系、肺系**疾病影响最明显。
- **韩玲**等：胚胎期前 3 个月所禀运气因素对体质形成影响显著。
- **平和质分布**：天干癸 + 太阳寒水客气 + 阳明燥金司天/少阴君火在泉年出生者**不易**成平和质。
- **阳虚质**：厥阴风木司天 + 少阳相火在泉之年（上一年寒湿主令）→ 易感寒湿伤阳。
- **阴虚质**：岁运火运不及 + 阳明燥金司天/少阴君火在泉 + 二之气主气 → 阴虚形成率增加。

### 5.2 体质 → 疾病易感性（王琦九体，实证扎实）

- 王琦团队 **40 万+ 流调**，建立体质类型与 **313 个病种**对应（已纳入国家公共卫生服务体系，九体判定为国标）。
- 痰湿质 → 高血压/高血脂/高血糖/多囊卵巢；气郁质 → 原发性青光眼；湿热/痰湿 → 新冠；阴虚 → 糖尿病/中风/失眠；阳虚 → 大肠癌（保护因素：平和/痰湿）；痰湿 → 痛风/代谢综合征。
- 「**体质土壤学说**」：特定体质是特定疾病的共同土壤 → 与 asset33「运气格局 × 疾病易感性」逻辑同构。

### 5.3 具体运气-体质-疾病 研究样例

- **类风湿关节炎 2306 例**（2019–2024，贵州中医大二附院）：胎孕期岁运**少金**频次最高；**少阳相火司天 + 厥阴风木在泉**最常见；**太火 + 太阴湿土司天 + 太阳寒水在泉**最常见禀赋；立秋/冬季出生最多；2023 初之气+四之运发病最多（主运太木/客运少火/主气厥阴风木/客气太阴湿土）。差异均 P<0.05。

### 5.4 对 P11 的可执行建议

- ✅ 在 `personal_yunqi_profile.py` 计算**先天运气**（出生年干支 → 岁运/司天/在泉 + 胎孕期运气，参考 5.1 的「胎孕期前 3 个月」权重），作为**一等输入**喂给 `infer_pathogenesis` 与体质评估。
- ✅ 把 5.1/5.3 的**具体映射规则**编码进 asset33 推理（如「火运不及+阳明燥金司天 → 阴虚质倾向」「厥阴风木司天+少阳相火在泉 → 阳虚质倾向」），让 earth/fire 维度在个人档案场景被**主动召回**。
- ✅ `cases_routing.py` 增加「体质→易感性→病证」分支，使 asset33 的 earth/fire 条目从「零查询」变为「按出生运气触发」。
- ✅ 新增回归/快照测试，验证 earth/fire 覆盖度回升（呼应 self-evolve 盲区日志）。
- ⚠️ **安全边界**：上述均为**关联性/统计学**证据，非因果；所有输出须保留现有免责声明与「不替代临床诊断」红线（asset33 与报告质量门已具备）。
